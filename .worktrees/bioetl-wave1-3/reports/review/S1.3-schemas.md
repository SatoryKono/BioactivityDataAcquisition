## Observations

1. **Consistent pattern:** All Gold schemas include system fields (`entity_id`, `content_hash`), DQ fields (`_dq_warn`, `_dq_error`), and metadata fields (`_run_id`, `_run_type`, `_source_batch_id`, `_ingestion_ts`, `_index`).
2. **Int->Float coercion:** Properly documented as EXC-007. Nullable integer handling via `Series[float]` with `coerce=True` is consistently applied.
3. **Strict mode:** All Gold schemas have `class Config: strict = True` for fail-fast validation.
4. **Schema registry:** `generated/registry.py` provides dynamic schema lookup, keeping domain schemas independent of infrastructure.
