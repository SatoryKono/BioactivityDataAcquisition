## File-by-File Notes

### pubchem/ (6 files)
- **`client.py`** (PubChemAdapter): Extends `BaseHTTPAdapter`. Uses `entity_mapper.py` for endpoint resolution. Supports CID/InChIKey batch lookup strategies.

- **`__init__.py`**: Clean re-exports.

- **`__init__.py`**: Clean re-exports.

### semanticscholar/ (4 files)
- **`adapter.py`** (SemanticScholarAdapter): Extends `BaseHTTPAdapter`. Batch paper lookup via POST endpoint. Supports both graph and search APIs.

- **`__init__.py`**: Clean re-exports.
