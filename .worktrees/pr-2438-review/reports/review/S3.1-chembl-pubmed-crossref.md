## File-by-File Notes

### chembl/ (8 files)
- **`client.py`** (ChEMBLAdapter): Extends `BaseHTTPAdapter`. Entity mapping via `entity_mapper.py`. Health check delegated to `health.py`. Proper structured logging.
- **`constants.py`**: Entity-to-endpoint mapping, rate limits. All UPPER_SNAKE_CASE.
- **`deduplication.py`**: In-memory deduplication with configurable capacity. Uses `time.perf_counter()` (deterministic).
- **`entity_mapper.py`**: Maps entity types to API endpoints. Pure logic, no I/O.
- **`health.py`**: Health check using `http_client.get_once()` + circuit breaker assessment.
- **`metadata.py`**: Extracts metadata from ChEMBL API responses. Pure parsing, no I/O.
- **`models.py`**: Pydantic models for API response validation. Includes `CHEMBL_RECORD_MODELS` registry.
- **`__init__.py`**: Clean re-exports with `__all__`.

### pubmed/ (8 files)
- **`pubmed_client.py`** (PubMedAdapter): Main adapter class. Uses `UnifiedHTTPClient`. Delegates fetch/search/health to separate modules.
- **`_fetch.py`**: Fetch logic with E-utilities `efetch` endpoint.
- **`_health.py`**: Health check via `einfo` endpoint.
- **`_search.py`**: ESearch implementation for PubMed search queries.
- **`constants.py`**: API base URL, endpoints, rate limits.
- **`fallback.py`**: `PubMedFallbackHandler` extending `BaseTitleFallbackHandler`. Three-phase title matching.
- **`models.py`**: Pydantic models for PubMed records.
- **`xml_processor.py`**: XML-to-dict conversion for PubMed's Medline XML format. Pure transformation.

### crossref/ (6 files)
- **`client.py`** (CrossrefAdapter): Extends `BaseHTTPAdapter`. DOI-based and filter-based fetching.
- **`batch.py`**: Batch processing utilities for Crossref filter ID slicing.
- **`exceptions.py`**: Custom exceptions (`CrossrefNotFoundError`).
- **`fallback.py`**: `CrossrefFallbackHandler` extending `BaseTitleFallbackHandler`.
- **`models.py`**: Pydantic models for Crossref API responses.
- **`__init__.py`**: Clean re-exports.
