# Указатель документации

Эта страница существует, чтобы поддерживать унаследованные ссылки на `INDEX.md`.

Используйте основные актуальные точки входа в документацию:

- [Карта проекта](00-project/00-map.md) — основной навигатор по актуальным документам проекта
- [Правила проекта](00-project/RULES.md) — канонические правила управления и политика рабочих процессов
- [Требования](01-requirements/REQUIREMENTS.md) — текущие проверяемые требования к проекту
- [Хаб инструментов](00-project/TOOLS.md) — актуальные точки входа скриптов и правила размещения

Актуальные материалы находятся в `docs/00-05`. Содержимое `docs/99-archive/`
сохраняет ценность для прослеживаемости, но не является нормативным для
текущего поведения проекта. Рассматривайте `docs/99-archive/README.md` как
путь в репозитории, а не как опубликованную страницу MkDocs.

Рабочие планы в `docs/plans/` — это материалы, существующие только в репозитории,
а сгенерированные артефакты в `docs/site/` и `docs/exports/` — это
ненормативные вспомогательные поверхности. Они могут быть полезны в локальных
рабочих процессах, но не заменяют каноническую документацию, публикуемую из
`docs/00-05`.

Затем при необходимости используйте точки входа в разделы:

- [Обзор проекта](00-project/index.md)
- [Требования](01-requirements/REQUIREMENTS.md)
- [Архитектура](02-architecture/00-overview.md)
- [Руководства](03-guides/getting-started.md)
- [Справочник](04-reference/cli.md)
- [Эксплуатация](05-operations/README.md)
- Путь репозитория `docs/99-archive/README.md` — индекс архива только для
  исторического контекста; не является нормативным
