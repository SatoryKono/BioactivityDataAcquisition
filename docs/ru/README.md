# Русские переводы документации

Этот каталог содержит русские (`ru`) переводы документации BioETL.

## Соглашение о локализации

- Путь к источнику (английский): `docs/<путь>.md`
- Путь к переводу (русский): `docs/ru/<путь>.md`

Дерево под `docs/ru/` зеркально повторяет структуру каталогов под `docs/`,
сохраняя те же имена файлов и относительные пути. Внутри каждого
переведённого файла:

- YAML frontmatter, имена компонентов, имена свойств, блоки кода и заголовки
  кодовых блоков сохраняются дословно из источника.
- Только текстовое содержимое (заголовки, абзацы, ячейки таблиц, текст
  ссылок) переводится на русский язык.
- Относительные ссылки внутри документа остаются неизменными; они должны
  разрешаться внутри дерева `docs/ru/` идентично основному дереву `docs/`.

## Статус

Начальный набор переведённых страниц охватывает корневые точки входа
документации. Дополнительные страницы переводятся по мере необходимости и
добавляются в этот каталог с использованием того же зеркального
расположения путей.

## Активация в MkDocs

Сборка MkDocs в настоящее время не включает `docs/ru/` в опубликованную
навигацию. Чтобы опубликовать русскую версию, добавьте плагин
[`mkdocs-static-i18n`](https://github.com/ultrabug/mkdocs-static-i18n) в
зависимости и настройте `docs_structure: folder` с `default_language: en`
и дополнительным языком `ru` в `mkdocs.yml`. До активации файлы под
`docs/ru/` действуют как поверхность для перевода, поддерживаемая в
синхронизации с английским источником.
