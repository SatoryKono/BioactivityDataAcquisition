## Критерии готовности

### Фаза 1 завершена когда:
- [ ] `Watermark` класс создан с фабричными методами
- [ ] Все пайплайны обновлены
- [ ] Backward compatibility с checkpoint storage
- [ ] Тесты проходят

### Фаза 2 завершена когда:
- [ ] Docstrings добавлены в observability модули
- [ ] OpenTelemetry интегрирован (опционально)
- [ ] Tracing можно отключить через config

### Весь рефакторинг завершён когда:
- [ ] Интегральный балл ≥ 8.9
- [ ] Все R11-R16 выполнены
- [ ] CI checks проходят

## Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Watermark migration breaks checkpoints | Средняя | Высокое | Backward compatibility, migration helper |
| OpenTelemetry overhead | Низкая | Среднее | Sampling, optional feature flag |
| E2E тесты нестабильны в CI | Средняя | Низкое | Nightly runs only, retry logic |
