## Критерии готовности

### Фаза 1 завершена когда:
- [ ] `bootstrap.py` создан с `AppConfig` и `Container`
- [ ] CLI использует `bootstrap()` вместо inline создания адаптеров
- [ ] `unified_storage.py` создан
- [ ] Вложенный `StorageAdapter` удалён из `chembl_activity.py`
- [ ] Все тесты проходят

### Фаза 2 завершена когда:
- [ ] `LockManager` выделен в отдельный класс
- [ ] `CheckpointManager` выделен в отдельный класс
- [ ] `RecordProcessor` выделен в отдельный класс
- [ ] `BasePipeline` < 100 строк
- [ ] `.importlinter` не содержит `ignore_imports`
- [ ] `lint-imports` проходит без ошибок

### Весь рефакторинг завершён когда:
- [ ] Интегральный балл ≥ 8.5
- [ ] Все R1-R10 выполнены
- [ ] Покрытие тестами ≥ 85%
- [ ] Все CI checks проходят

## Рекомендуемый порядок выполнения

```
1. [R2] StorageAdapter (1 день) - быстрая победа
   │
2. [R1] Composition Root (2-3 дня) - ключевое изменение
   │
3. [R5] DRY в CLI (0.5 дня) - зависит от R1
   │
4. [R4] Import-linter (0.5 дня) - зависит от R1
   │
5. [R3] Декомпозиция BasePipeline (3-5 дней) - сложное
   │
6. [R6, R7, R8] Параллельно (2-3 дня)
   │
7. [R9, R10] Чистка (0.5 дня)
```

## Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
