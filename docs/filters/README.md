# Filters Migration Working Folder

Working folder for the silver_filters → gold_filters migration program (variant D,
hybrid). Artifacts here are DRAFTS pending review by BioETL Team. After
acceptance, the ADR and any normative artifacts MUST be relocated to their
canonical locations (`docs/02-architecture/decisions/` for the ADR).

## Goal

Narrow `silver_filters` scope to structural integrity only
(`required_fields`, `exclude_if_present`); consolidate semantic filters
(`columns`, `ranges`, `list_length_filters`, `list_contains_filters`) into
`gold_filters`.

See: `ADR-048-silver-filters-structural-scope.md` (in this folder, draft).

## Inventory baseline summary (2026-05-12)

Generated by `scripts/data_quality/inventory_silver_filters_migration.py`.

- **Entities scanned**: 21
- **Entities with `silver_filters`**: 21
- **Entities with `gold_filters`**: 21
- **Total rules**: 100
  - **keep_in_silver**: 81 (structural — stay in silver_filters)
  - **move_to_gold**: 5 (semantic, missing in gold — must be moved)
  - **duplicate**: 14 (semantic, identical in gold — drop from silver)
  - **conflict**: 0 (semantic mismatch — would require manual review)

**Key finding:** zero conflicts. The migration is technically safe — no
silver/gold semantic rule diverges between layers.

### Structural surface (`keep_in_silver`)

81 structural rules across 21 entities. Of these, ~30 also appear under
`gold_filters.required_fields` (informational note in inventory). A separate
review SHOULD decide whether to deduplicate `required_fields` between silver
(structural completeness) and gold (business critical fields), but this is
OUT OF SCOPE for ADR-048.
