## Function / Class Surface Snapshot

- `metadata_builder.py`
  - classes: `SilverMetadataBuilder`, `GoldMetadataBuilder`
  - key seam: imports `build_composite_output_ext` from infrastructure helper module
- `metadata_writer_operations.py`
  - dataclasses: request/target/prepared/telemetry/retry/final outcome models
  - pipeline: request -> target resolve -> YAML serialize -> retry callback -> final telemetry
- `metadata_writer.py`
  - public contract: `write_bronze_metadata`, `write_silver_metadata`, `write_gold_metadata`
  - internal orchestration pipeline around `_prepare_metadata_write_operation`
- `metadata_assemblers_helpers.py`
  - application-side parsing/assembly helpers for composite metadata and runtime/lineage/delta
- `metadata_builder_composite_helpers.py`
  - infrastructure-side parsing/assembly helpers duplicating composite parsing semantics
