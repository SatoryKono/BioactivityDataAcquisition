## Goal

## Delivered Changes

### 1) Baseline + seam inventory freeze

- Added [rf-015-baseline-2026-03-17.md](rf-015-baseline-2026-03-17.md) with:
  - in-scope/out-of-scope boundaries;

  - `_get_runner_logger`
  - `_handle_destructive_run_confirmation`

### 3) Service accessor moved out of command module

- Added private module:
  - `src/bioetl/interfaces/cli/commands/run_service_access.py`
- Moved process-local cache state there.
- Kept `run.py` seam `get_cli_run_orchestration_service()` as thin wrapper.

### 4) Runtime path consolidation

- Extended `run_runtime_helpers.py` to host canonical runtime helpers:
  - `run_pipeline_async(...)`
  - `run_prepared_request_async(...)`
  - `build_run_pipeline_callable(...)`
- Added dependency-injection parameters for runtime collaborators so `run.py`
  patch seams stay effective (`get_pipeline_runner_service`,
  `ensure_metrics_server_started`, `health_server_context`).
- Updated `run.py` runtime functions to delegate to helper implementations while
  preserving existing symbol names:
  - `_run_pipeline_async(...)`
  - `_run_prepared_request_async(...)`

### 5) Result/presentation glue extracted

- Added private module:
  - `src/bioetl/interfaces/cli/commands/run_result_flow_helpers.py`
- Moved reusable glue logic there:
  - `present_run_health_info(...)`
  - `finalize_run_result(...)`
- Kept `run.py` wrappers `_present_run_health_info` and `_finalize_run_result`
  with the same patchability semantics expected by tests.

### 6) `run.py` thin-entrypoint finish

- Replaced redundant wrappers with patchable aliases:
  - `_build_run_command_input = _build_run_command_input_impl`
  - `_map_status_to_exit_code = map_status_to_exit_code`
- Reduced `run.py` size from `400 LOC` to `372 LOC`.
