## Visual verification protocol

The immutable live capture is intentionally performed from the resulting
`main` commit, after this layout change merges. The required evidence is:

1. all seven dashboards at 1920×1080, dark theme, kiosk/full mode, 100% zoom,
   default variables and default row state;
2. default-row full-page and force-expanded full-page captures;
3. close-ups for Trust panels `9413–9417`, Overview current row `9030`, DQ
   panels `9101–9102`, and Incident panel `2006`;
4. immutable manifest with commit SHA, dashboard JSON SHA-256, exact PNG file
   set and hashes, theme/viewport/zoom/variables/time/row state, and terminal
   panel classifications;
5. explicit review of overlap, clipping, internal scroll, query errors,
   no-data semantics, state transitions, and operator-fact preservation.

accepted immutable baseline is rooted at

## Visual acceptance result

**Accepted.** The default-row first fold, default-row full-page, and
force-expanded full-page images were reviewed for all seven dashboards. The
canonical full-set manifests contain exactly seven PNGs each, all dashboard
JSON hashes match the reviewed source, and the render preflight reports no
`RENDER_ERROR`.

- Trust: the real expanded Grafana render preserves the operator guidance,
  clearly exposes `UNKNOWN`/`INCOMPLETE` without false-green states, and shows
  panels `9413–9417` without overlap or clipping. The separate fixture HTML
  close-up matrix is not represented as a live Grafana render; it was used to
  verify the same table fields for populated, valid-empty/unknown,
  backend-error, HTTP 503, and Infinity `noValue` states.
- Overview: the current-state row, First Action, domain status, range evidence,
  diagnostics, and run context remain legible with explicit no-data semantics
  and no overlap, clipping, or internal scroll.
- Data Quality: panels `9101–9102`, range evidence, and expanded diagnostics
  remain legible. Current `UNKNOWN` and missing evidence are explicit even when
  historical/range data contains a 100% score.
- Incident: panel `2006` renders at `24x8` with FIRING/PENDING history visible
  and no internal scroll. Downstream panels remain aligned and non-overlapping.

The acceptance evidence and machine-readable status are stored beside the
ignored local baseline as `VISUAL_ACCEPTANCE.md`, `CAPTURE_SUMMARY.json`, and
`RF002_BASELINE_STATUS.json`. Immutable render manifests and PNGs were not
