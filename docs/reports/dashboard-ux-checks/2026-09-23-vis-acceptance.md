## Проверки и границы доказательств

- Финальный целевой прогон: **254 passed, 1 skipped**; [лог](assets/2026-09-23-vis-acceptance/accepted-final-tests.txt). Включает mandatory operator-readability / first-window gates, units, visual semantics, CTA links, selection actions, state fixtures, HTTP recent-run / selected-run tests. Skip относится к удалённому workflow-overview dashboard. Ruff, canonical generator `--check` и Scenes parity `--check` прошли.
- [Event age receipt](assets/2026-09-23-vis-acceptance/accepted-event-age.json) связывает значение с completed_at и интервалом HTTP-запроса. Переход к report дополнительно проверен по полному UUID и pipeline identity.
- Live наблюдались SELECT RUN, успешный selected run с WARN / INCOMPLETE, UNKNOWN / missing telemetry, пустая Silver detail без reject samples, PENDING / FIRING и настоящий QUERY ERROR. При transient timeout каталога появлялся красный индикатор Run ID; на Overview источник вернул QUERY ERROR. Это не объявлено успешной телеметрией. Следующее успешное получение SELECT RUN проверено в Incident.
- Историческое состояние «ноль ranked suspects» на текущих данных не повторилось: теперь есть реальные suspects. Footer отключён для полной таблицы независимо от количества строк; описание различает successful empty, UNKNOWN и QUERY ERROR. Новая browser-проверка нулевого списка не заявляется. Отдельная полная браузерная матрица каждого состояния на каждом дашборде и prometheus-only profile не выполнялась; метрики не подменялись, новые pipeline runs для наполнения не запускались.
- GitHub Actions для исходного merge был заблокирован billing до старта job (run 35833060422 / job 107089953548): **CI=BLOCKED_EXTERNAL**. Локальные проверки не заменяют CI. Общие governance/architecture failures, описанные в предыдущем отчёте, и общий Sonar main gate не объявлены исправленными. Родительские задачи #10554 / #10571 сохраняют отдельную приёмку всего observability контура.
- Runtime/skills и `.env` не менялись; AI mirror sync неприменим. Финальный tail не меняет `src/bioetl`, поэтому source-tree inventory refresh не требуется. Документационный inventory обновляется вместе с этим отчётом.

## Общие изменения и порядок приёмки

Сначала исправлены неверная семантика возраста и наложения временных дорожек (P1), затем ссылки на evidence, таблицы и пустые/ошибочные состояния (P2), затем единая типографика и плотность (P3). Stage identity отделена от severity; отсутствие телеметрии не окрашивается в OK. Навигация сохраняет общий scope и time range, подробные evidence остаются в раскрываемых группах. В длинных таблицах сохранены все строки и штатный вертикальный scroll/pagination, а полный UUID доступен через ссылку и report.

Проверенные дашборды: **0. Run Explorer; 1. Trust; 2. Overview; 3. Pipeline Diagnostics; 4. Provider Health; 5. Data Quality; 6. Incident Workspace**.
