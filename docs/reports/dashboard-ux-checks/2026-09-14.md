## State semantics

- UNKNOWN: insufficient evidence to determine health; no selected-stage catalog
  remains UNKNOWN.
- VALID EMPTY: a measured zero or a successful, explicitly complete empty result.
  An absent metric is not mapped to this state.
- TELEMETRY MISSING: missing series or required evidence for the requested scope.
- QUERY ERROR: datasource/query failures retain Grafana's error state. No failure
  injection was performed against the running services in this pass.
- SELECT RUN and REPORT MISSING distinguish unresolved scope and absent history.
