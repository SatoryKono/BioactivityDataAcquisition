## Scope

- all seven shipped dashboards at physical viewport `1366×768`;
- dark and light themes at browser zoom `100%` and `200%`;
- authored text font remediation for inline code and three operator guidance
  panels;
- no dashboard query, metric, selector, datasource, verdict, or alert-rule
  change.

## Render contract

The `200%` profile uses browser reflow semantics: CSS layout viewport
`683×384` with `devicePixelRatio=2`, producing a physical `1366×768` PNG.
Root CSS `zoom` is not used. This keeps responsive layout behavior observable
instead of magnifying the desktop layout and manufacturing horizontal
overflow.

BioETL-authored panel content is checked at `16px` body and `18.67px` title
minimums. Grafana-managed chrome uses the pinned Grafana 12 baseline of
`12px` body and `14px` panel titles and must pass the 200% reflow matrix.
Global CSS overrides and screenshot-time style injection remain forbidden.
