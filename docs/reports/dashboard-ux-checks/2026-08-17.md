# Dashboard UX check — 2026-08-17 first-window containment and P1 tables

## Scope

- first-window internal panel containment gate (`#8896`);
- Provider Health bounded tables and fold reflow (`#8900`);
- Incident cross-domain top-five ranking (`#8902`);
- Run Explorer bounded first-window summaries (`#8903`);
- compact first-window operator copy on Overview, Trust, Pipeline Diagnostics,
  and Data Quality without changing first-window geometry or typography;
- Overview panel `9002` (`Review Domain Status`) capped to four
  deviation-first rows;
- full six-domain matrix preserved as panel `9031`
  (`Review All Domain Status`) under collapsed Domain Status Tracks.

## Semantic contract review

- CURRENT / SELECTED RUN / TIME RANGE and fail-closed UNKNOWN wording remain
  visible on Overview and Trust scope banners.
- Pipeline Diagnostics no longer presents SCRAPING as proof of delivery
  health; coverage caveats stay in the panel description.
- Data Quality still separates current verdict, selected-run accounting, and
  range SLA/freshness.
- Trust recovery copy no longer uses `overflow:hidden` to hide required
  action text.
- No `run_id`, `manifest_id`, payload hash, record ID, or other
  high-cardinality Prometheus label was introduced.
- Missing data remains explicit; this change does not convert missing evidence
  into a healthy state.

## Static verification

- dashboard JSON syntax validation;
- focused Grafana first-screen, overview, runtime CTA, and render-first
  contracts;
- dashboard inventory panel count, panel-title inventory, and ADR-053
  JSON-to-Scenes parity ledger regeneration.

## Visual verification protocol

The #8896 containment helpers and fail-closed schema are in the Playwright
render script. Static tests cover first-window panel selection, row-cap
ownership, manifest schema, and fail-closed overflow evaluation. The populated
7-dashboard dark/light × 100%/200% matrix at `1366x768` still requires an
opt-in Grafana render host; this change does not start monitoring Docker.
