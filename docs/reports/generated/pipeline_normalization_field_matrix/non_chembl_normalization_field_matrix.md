# Pipeline Normalization Field Matrix

Generated from active pipeline configs, Silver schemas, domain schema contracts, DQ policy configs, and current normalization code paths.

This matrix is a normalization inventory, not a persisted-row publication contract.
Occurrence-scoped provenance fields may appear here because normalization or config policy still references them,
but canonical Silver/Gold row contracts are defined by provider references and Gold contract exports.

Governance columns expose controlled-vocabulary sources, content_hash scope, content_hash inclusion, hash ordering, semantic category, strictness, domain/Silver schema visibility, and DQ rule visibility for each field.
