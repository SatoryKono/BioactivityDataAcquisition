## Implemented Changes

1. Shared pure seam introduced in domain
   - Added `composite_metadata_helpers.py` with pure, I/O-free functions:
     - `parse_composite_list`
     - `parse_composite_status`
     - `parse_lineage_created_at`
     - `extract_composite_output_ext`
2. Application helper switched to shared seam
   - `metadata_assemblers_helpers.py` now delegates composite parsing/extraction helpers to domain module instead of keeping duplicate parsing implementation.
3. Infrastructure composite helper converted to compatibility wrappers
   - `metadata_builder_composite_helpers.py` now delegates to domain seam and keeps existing helper names for downstream compatibility.
4. `GoldMetadataBuilder` simplified around output assembly
   - `metadata_builder.py` now calls domain seam directly for composite output extraction.
   - Duplicated fallback/merged output path assembly is unified via `_build_output_with_composite_ext`.
5. `metadata_writer_operations.py` preparation pipeline simplified
   - Removed `_PreparedMetadataWriteArtifacts`.
   - Reduced preparation flow to one explicit path:
     - `request -> target -> prepared_write -> telemetry_context -> prepared_operation`
   - Retry/final telemetry event names and semantics preserved.
