# Cross-Synthesis: Topology vs Governance Signals

Status: active

## Intersection Analysis

Package topology families align with governance signal hotspots:

- **Adapter family** overlaps with VCR cassette governance and environment-limited
  test skip budgets.
- **Storage family** overlaps with schema drift detection and DQ gate thresholds.
- **Bootstrap runtime family** overlaps with composition complexity and fan-in
  metrics.

This cross-synthesis confirms that family-level structural watchlists are the
right granularity for CI governance ratchets.
