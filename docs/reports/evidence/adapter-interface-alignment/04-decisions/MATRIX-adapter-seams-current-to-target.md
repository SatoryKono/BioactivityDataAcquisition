## Proposed Normalization Rules

1. Runtime callers should depend on typed provider-bound creators, not on dynamic adapter kwargs.
1. Helper synthesis should have one canonical policy owner per seam family, not one per provider.
1. `custom_creator` should become an internal composition seam with an explicit protocol, not an open-ended registry escape hatch.
1. Specialized creators with real external-input semantics, such as `uniprot_idmapping`, should stay typed and provider-specific.
1. Composite runtime bootstrap should be treated as the reference pattern for explicit plan-based composition and typed collaborator bundles.
