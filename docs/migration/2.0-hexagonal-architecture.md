# Migration Guide: Hexagonal Architecture (v2.0)

## Overview
Version 2.0 introduces strict layer separation. This guide helps migrate
existing code.

## Breaking Changes

### 1. Parser returns dict instead of typed models

Before:
```python
parser = ChemblResponseParserImpl(ActivityRawModel)
records: list[ActivityRawModel] = parser.parse(response)
```

After:
```python
parser = ChemblGenericResponseParser()
raw_records: list[dict] = parser.parse_to_records(response)

# If typed records needed:
mapper = ChemblRecordMapper()
typed_records = mapper.map_records(raw_records, "activity")
```

### 2. Extraction service returns generic types

Before:
```python
for batch in service.iter_extract("activity"):
    for record in batch:  # record: RawRecord
        process(record.activity_id)  # Typed access
```

After:
```python
mapper = ChemblRecordMapper()
for batch in service.iter_extract("activity"):
    typed_batch = mapper.map_records(batch, "activity")
    for record in typed_batch:
        process(record.activity_id)  # Typed access after mapping
```

### 3. Config loading requires bootstrap

Before:
```python
config = get_pipeline_config("chembl.activity")
```

After:
```python
container = PipelineContainer()
container.bootstrap()  # Required!
config = get_pipeline_config("chembl.activity")
```

## New Components

| Component | Layer | Purpose |
|-----------|-------|---------|
| `ChemblGenericResponseParser` | Infrastructure | Parse API responses to dict |
| `RecordMapperABC` | Application | Contract for record mapping |
| `ChemblRecordMapper` | Application | ChEMBL-specific mapper |
| `SchemaBootstrapService` | Application | Schema registration lifecycle |
| `SchemaContractProviderABC` | Domain (port) | Schema contract access |
