# Аудит документации BioETL

**Дата:** 2025-12-15
**Статус:** Черновик (Обновлено)

## 1. Резюме (Executive Summary)

В ходе аудита документации выявлены критические несоответствия правилам проекта (`RULES.md` v5.0) и фактическому состоянию репозитория:
1.  **Отсутствие кодовой базы:** Директория `src/`, описанная в документации как местоположение исходного кода, полностью отсутствует.
2.  **Избыточное дублирование:** Файл `RULES.md` в корне и файлы в `docs/00-project_rules/` содержат идентичную информацию, что создает путаницу.
3.  **Нарушение языковых требований:** Значительная часть документации (вся папка `docs/01-architecture/`) написана на английском языке, что противоречит требованию о русскоязычной документации.
4.  **Отсутствующие артефакты:** Не найдены директории `docs/contracts/gold/` и `docs/runbooks/`, а также конфигурационные файлы `abc_registry.yaml` и `abc_impls.yaml`.

## 2. Структурный анализ (Structure Analysis)

### 2.1. Критическое несоответствие структуры
Документация описывает структуру, которой нет в репозитории:
*   **Ожидается:** `src/bioetl/` (Application, Domain, Infrastructure).
*   **Фактически:** Директория `src` отсутствует. Присутствуют только `docs/`, `data/` и `RULES.md`.

### 2.2. Конфликт `RULES.md` и `docs/00-project_rules/`
Текущая ситуация:
*   **`RULES.md` (Root):** Полная версия правил v5.0.
*   **`docs/00-project_rules/`:** Набор файлов, дублирующих `RULES.md`.

**Рекомендация:**
1.  Оставить `RULES.md` только как навигационный индекс.
2.  Перенести уникальный контент в структуру `docs/standards/`, `docs/governance/`.
