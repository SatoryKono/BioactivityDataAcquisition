## 4. План Рефакторинга

### Фаза 1: Критические Исправления (HIGH Priority)

1. **Включение Mypy для всех слоёв** — удалить `ignore_errors = true`
2. **Инъекция LoggerPort в адаптеры** — заменить `logging.getLogger` на LoggerPort

### Фаза 2: Архитектурные Улучшения (MEDIUM Priority)

1. **Устранение нарушения матрицы импортов** — infrastructure → application
2. **Консолидация паттернов адаптеров** — PaginatedFetcherMixin

### Фаза 3: Качество и Безопасность (LOW Priority)

1. **Pre-commit hooks**
2. **Mutation testing в CI**
3. **Contract tests для API**
