## 5. Locking & Concurrency (§3.3)

### Distributed Lock with Heartbeat

```
Worker A                          Redis                          Worker B
   │                                │                                │
   │ SETNX lock:chembl_activity     │                                │
   │ owner=A, TTL=60s               │                                │
   ├───────────────────────────────►│                                │
   │                                │                                │
   │ OK                             │                                │
   │◄───────────────────────────────┤                                │
   │                                │                                │
   │                                │  SETNX lock:chembl_activity    │
   │                                │◄───────────────────────────────┤
   │                                │                                │
   │                                │  FAIL (lock exists)            │
   │                                ├───────────────────────────────►│
   │                                │                                │
   │ heartbeat (every 20s)          │                                │
   │ EXPIRE if owner=A              │                                │
   ├───────────────────────────────►│                                │
   │                                │                                │
   │ ... processing ...             │                                │
   │                                │                                │
   │ validate_ownership()           │                                │
   │ before delta write             │                                │
   ├───────────────────────────────►│                                │
   │                                │                                │
   │ OK (owner=A)                   │                                │
   │◄───────────────────────────────┤                                │
   │                                │                                │
   │ DEL lock if owner=A            │                                │
   ├───────────────────────────────►│                                │
   │                                │                                │
```
