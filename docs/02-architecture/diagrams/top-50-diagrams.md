# TOP-50 Архитектурных Диаграмм BioETL

*Версия: 1.0 | Дата: 2026-01-20*

Таблица 50 наиболее важных диаграмм для понимания архитектуры, логики и кодовой базы проекта BioETL, отсортированных по приоритету.

**Методология приоритизации (v2):**

- **ArchitectureImpact** (1-10): влияние диаграммы на архитектурные решения и соблюдение layer/DDD принципов.
- **CodeCoverage** (1-10): охват ключевых модулей, слоёв и портов/адаптеров в кодовой базе.
- **ComplexityReduction** (1-10): насколько диаграмма снижает когнитивную сложность при анализе кода.
- **OperationalValue** (1-10): польза для эксплуатации, диагностики инцидентов и runbook-сценариев.
- **OnboardingValue** (1-10): ценность для ускорения онбординга новых разработчиков.
- **Priority** = `(ArchitectureImpact + CodeCoverage + ComplexityReduction + OperationalValue + OnboardingValue) / 5`.

### Источники оценок

- **Код**: структура слоёв, orchestration и storage-потоки (`src/bioetl/*`) и связанный runtime-контур.
- **Документация**: ADR, guides, reference и архитектурные разделы `docs/*`.
- **Операционные сценарии**: runbooks, preflight/checkpoint/retry/observability и troubleshooting-практики.
