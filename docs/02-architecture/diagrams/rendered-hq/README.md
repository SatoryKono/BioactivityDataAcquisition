# HQ Renders

This directory contains high-readability exports for dense diagrams.

- Scope: `*-full.mermaid` diagrams.
- Outputs:
  - `png/*.png` high-resolution raster (`scale=4`, larger canvas)
  - `svg/*.svg` vector (best for zoom/readability)
- Render status: `31/31` successful.

Recommended usage:
1. Open `svg` first for infinite zoom.
2. Use `png` when image embedding is required.
