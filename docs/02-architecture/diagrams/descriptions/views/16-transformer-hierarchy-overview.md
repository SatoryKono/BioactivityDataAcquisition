# Transformer Hierarchy Overview

- Исходная диаграмма: `views/16-transformer-hierarchy-overview.mermaid`

## Описание

Эта views-диаграмма Transformer Hierarchy Overview представляет срез типа overview для родительской схемы 16-transformer-hierarchy.mmd и использует нотацию flowchart. Она нужна для быстрого понимания того, как BaseTransformer расходится в основные provider-oriented ветки и где подключается extractor pattern. В метке view зафиксировано назначение: Overview. Показательные узлы в диаграмме: BaseTransformer, ChEMBL, Publication, UniProt, Other, Extractor Pattern. Такой срез помогает на ревью быстро сверять high-level transformer narrative с текущей организацией pipeline transformers в приложении.
