# Port Protocol Contracts Overview

- Исходная диаграмма: `views/13-port-protocol-contracts-overview.mermaid`

## Описание

Эта views-диаграмма Port Protocol Contracts Overview представляет срез типа overview для родительской схемы 13-port-protocol-contracts.mmd и использует нотацию flowchart. Она нужна как low-density summary карты доменных портов, их implementation catalog и governing contract rules. В метке view зафиксировано назначение: Overview. Показательные узлы в диаграмме: Domain Port Catalog, Implementation Catalog, Import Matrix / Contracts. По ним удобно сверять, что архитектурный narrative о портовом фасаде, адаптерах и import matrix остаётся целостным даже в сильно упрощённом представлении.

## Метаданные

- Тип: `flowchart`
- View: `Overview`
- Parent: `13-port-protocol-contracts.mmd`
