# Слой Interfaces (Интерфейсы)

**Расположение:** `src/bioetl/interfaces/`

## 1. Назначение

Слой `Interfaces` — это точка входа в приложение. Он отвечает за приём команд от пользователя (или других систем) и запуск соответствующей бизнес-логики. Это единственный слой, который может импортировать модули из всех остальных слоёв.

Именно здесь находится **Composition Root** — место, где собираются вместе все зависимости приложения.

**Ключевые характеристики:**
- **Точка входа:** Содержит код, который запускается напрямую (например, CLI-команды).
- **Сборка зависимостей:** Создаёт экземпляры адаптеров из `Infrastructure` и передаёт их в пайплайны из `Application`.
- **Адаптация ввода/вывода:** Преобразует внешние запросы (например, аргументы командной строки) в вызовы методов слоя `Application`.

## 2. Ключевые Компоненты

### 2.1. `bootstrap.py` — Composition Root

**Источник:** `src/bioetl/composition/bootstrap.py`

> **Примечание:** Composition Root перенесён в отдельный слой `composition/` согласно ADR-005.

Это самый важный файл в слое. Он выполняет следующие задачи:
1.  **Загрузка конфигурации:** Читает переменные окружения и конфигурационные файлы.
2.  **Инстанцирование адаптеров:** Создаёт экземпляры всех необходимых адаптеров (`RedisLockAdapter`, `S3StorageAdapter`, `ChemblAdapter` и т.д.), передавая им нужные конфигурации.
3.  **Сборка пайплайнов:** Создаёт экземпляры пайплайнов из `Application`, внедряя в них созданные адаптеры.

Этот файл — единственное место в системе, где нарушается правило "не зависеть от конкретных реализаций". Это делается намеренно, чтобы вся остальная система оставалась чистой.

### 2.2. `cli.py` — Интерфейс Командной Строки

**Источник:** `src/bioetl/interfaces/cli.py`

Реализует CLI для взаимодействия с пользователем. Использует библиотеки вроде `Typer` или `Click` для определения команд.

**Пример команды:**
```bash
python -m bioetl.cli run-pipeline --pipeline-name chembl_activity --full-rebuild
```

`cli.py` парсит эти аргументы, обращается к `bootstrap.py` для получения уже собранного экземпляра `ChemblActivityPipeline` и вызывает его метод `run()`.

## 3. Принципы Работы

- **Максимальная простота:** Этот слой должен быть как можно более "глупым". Его задача — делегировать работу другим слоям, а не выполнять её самому.
- **Единственная ответственность:** Единственная ответственность этого слоя — запуск приложения и управление его жизненным циклом на самом верхнем уровне.
- **Импорт из всех слоёв:** Это единственный слой, которому разрешено импортировать модули из `domain`, `application` и `infrastructure` для того, чтобы "собрать" приложение воедино.
