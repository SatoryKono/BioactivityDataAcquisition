❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Do I need to edit any files?
A: No. The startup script creates everything automatically.

Q: What if localhost doesn't work from WSL?
A: That's expected. Use host.docker.internal instead.

Q: What if host.docker.internal doesn't work?
A: Restart Docker Desktop. If still broken, check WSL integration is enabled.

Q: Can I run this from Windows instead of WSL?
A: Yes, but use localhost:7687 instead of host.docker.internal:7687

Q: How much disk space do I need?
A: ~2GB for Neo4j container + data.

Q: Can I change the password?
A: Yes, edit the startup script's -e NEO4J_AUTH= parameter before running.
