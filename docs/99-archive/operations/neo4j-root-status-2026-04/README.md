# Neo4j Root Status Wave Archive (2026-04)

*Status: archive (repo-only, non-canonical)*

## Purpose

This archive stores the April 2026 root-level Neo4j / MCP / Windows recovery and
verification wave that was intentionally removed from the repository root during
structure cleanup issue `#2836`.

These files remain useful as historical evidence and troubleshooting context,
but they are not the default operator workflow.

## Use This Archive When

- you need historical recovery notes from the 2026-04 Neo4j stabilization wave;
- you need to inspect prior status / final-summary artifacts preserved for
  traceability;
- you are reconciling old issue discussions or historical operator commands.
