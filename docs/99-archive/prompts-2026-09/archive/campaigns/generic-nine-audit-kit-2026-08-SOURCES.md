# Sources note — generic nine-domain audit kit

The operator-supplied megaprompt used inline markers `[S1]`…`[S11]` without a
bibliography. **Do not treat those markers as verified URLs.**

When re-authoring domain cards or campaign text, prefer:

| Topic | Prefer linking |
| --- | --- |
| GitHub community health / README | GitHub Docs — about READMEs, CONTRIBUTING, SECURITY |
| Diátaxis | https://diataxis.fr/ |
| Google developer style | Google Developer Documentation Style Guide |
| Microsoft writing style | Microsoft Writing Style Guide |
| GitHub relative links | GitHub Docs — relative links |
| pytest | https://docs.pytest.org/ |
| Jest coverage | Jest docs — configuration / coverageThreshold |
| Playwright retries / CI | Playwright docs — test retries, CI |
| Git ignore / clean | https://git-scm.com/docs/gitignore , git-clean |
| GitHub Actions security | GitHub Docs — security hardening for GitHub Actions |
| Action pinning (full SHA) | GitHub Docs — using third-party actions securely |
| OIDC cloud auth | GitHub Docs — OIDC |
| C4 model | https://c4model.com/ |
| arc42 | https://docs.arc42.org/ |
| Mermaid | https://mermaid.js.org/ |
| Copilot / AGENTS.md | GitHub Docs — customizing Copilot / agents (verify current path) |

**BioETL SSOT always wins** over external style guides when they conflict
(`AGENTS.md`, `NORMATIVE_SOURCES.md`, accepted ADRs, runtime trees).
