## Why now

- Scope collision (NOW/RANGE/RUN/GLOBAL) without visual grammar
- UNKNOWN as universal container
- Giant words/zeros consuming first viewport
- Cross-dashboard contradictions at the same selection (Runtime SCRAPING vs Gold accounting; Provider 0/0 green; Trust Safety OK vs INCOMPLETE; Incident cross-pipeline suspect)
