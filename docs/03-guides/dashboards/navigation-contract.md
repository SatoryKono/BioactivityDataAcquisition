# Grafana Navigation Contract

Канонический контракт навигации для shipped dashboard UIDs в `grafana/dashboards/*.json`.

Machine-readable SSOT: `docs/03-guides/dashboards/contracts/navigation-links.yaml`.

The shipped portfolio contains five dashboards. Replay Readiness, Run Overview,
Data Quality and Incident Workspace expose the same `h=2` header bus:

`Run Explorer` · `Replay Readiness` · `Run Overview` · `6. Incident Workspace`

The current workspace is disabled (`aria-current="page"`) when it is a bus
item; machine-readable links on panel `1000` omit that self-link. Data Quality
is a contextual detail destination rather than a header item.

Run Explorer uses the exact-run actions in table `3010` instead of a header
bus. Its Overview, Saved Evidence, Data Quality and Replay Readiness columns
pass the clicked row's Run ID, pipeline, workflow and run type. A page-level
Run ID must not replace the row identity. Returning through the Run Explorer
header link clears the selectors and search field while preserving time.

`navigation_surfaces` and `navigation_transition_contract` in the YAML define
these two navigation surfaces and the required paths. Data Quality is reachable
from the run table; a Replay Readiness / Run Overview round trip remains direct.
All dashboard-owned links set `includeVars=false` and explicitly serialize
allowlisted context plus `${__url_time_range}`.

Nav HTML is generated by `scripts/ops/observability/grafana/render_nav_bus.py`.
Links retain visible names and native tooltips after sanitization. The header
has no visible Navigate Dashboards heading; its metadata title remains available.

Selection handoffs use `${variable:queryparam}`; mapped scalar context uses
`var-target=${variable:percentencode}`. Selection URLs preserve the selected All
sentinel and serialize multiple values as repeated URL parameters. Datasource
regex/glob interpolation is reserved for queries. `Set range to run` reads
retained, hidden frame fields `from_ms` and `to_ms`; missing timestamps leave
the action unavailable. Ranked Suspects opens the row domain and pipeline.
Run Explorer artifact links use the read-only Ops HTTP artifact endpoint, which
accepts the selected pipeline, run ID, and the JSON/Markdown format only.

Adjunct Explore handoffs for Loki/Tempo and the Silver Reject Explorer dashboard
were **removed 2026-07-23** (see
[monitoring-surface-reduction](../../05-operations/runbooks/monitoring-surface-reduction-2026-07-23.md)).
Links use solid contrast-safe colors and wrap at `1024px`; horizontal clipping and
light-theme white-on-white states are defects.

YAML также фиксирует time handoff policy в `time_handoff_requirements`:
- `dashboard_links.required_tokens`: `${__url_time_range}`

## Нормативный источник

Единственный нормативный источник link/vars/time semantics: `docs/03-guides/dashboards/contracts/navigation-links.yaml`.

- Минимальный narrative закреплён в YAML: `normative_source.narrative_minimal`.
- Нормативные ключи для проверок: `required_top_level_links_by_uid`, `required_link_vars_by_target_uid`, `allowed_dashboard_link_vars`, `forbidden_dashboard_link_vars_by_target_uid`, `time_handoff_requirements`, `default_time_refresh_policy`, `navigation_transition_contract`.
- Этот Markdown — explanatory mirror: допускаются примеры и навигация, но не дублирование нормативных MUST-правил.

## Примеры URL (нормализованный формат)

- Dashboard: `/d/bioetl-overview-v2/2-overview?var-pipeline=$pipeline&var-run_type=$run_type&${__url_time_range}`
- Dashboard: `/d/bioetl-dq-v2/bioetl-dq-v2?var-pipeline=$pipeline&var-run_type=$run_type&var-stage=$stage&${__url_time_range}`
- Dashboard: `/d/bioetl-overview-v2/bioetl-overview-v2?var-pipeline=unknown&var-run_type=All&${__url_time_range}`
- Provider context mapping (fail-closed): `/d/bioetl-provider-health-v2/bioetl-provider-health-v2?var-provider=unknown&var-pipeline_context=$pipeline&${__url_time_range}`
- Provider (fail-closed): `/d/bioetl-provider-health-v2/...?var-provider=unknown&var-pipeline_context=$pipeline&${__url_time_range}`
- Incident: `/d/bioetl-incident-v1/bioetl-incident-v1?var-pipeline=$pipeline&var-run_type=$run_type&${__url_time_range}`
- Run Explorer: `/d/bioetl-run-explorer-v1/bioetl-run-explorer-v1?var-pipeline=$pipeline&var-run_type=$run_type&${__url_time_range}`
