# Cheatsheets

Краткие справочники для быстрого поиска и ежедневной работы.

## Purpose

Эта директория содержит cheatsheets — одностраничные справочники для быстрого доступа к часто используемым командам, паттернам и процедурам.

## Available Cheatsheets

| Cheatsheet | Description |
| ---------- | ----------- |
| [CLI Commands](cli-commands.md) | Краткий справочник по всем командам BioETL CLI |

## Usage

Используйте cheatsheets для:
- Быстрого поиска команд без чтения полной документации
- Повседневных операций, когда вы уже знакомы с системой
- Обучения новых участников команды

## Contribution

При добавлении нового cheatsheet:
1. Создайте файл в этой директории
2. Добавьте запись в таблицу выше
3. Обновите [../index.md](../index.md) при необходимости
4. Следуйте формату существующих cheatsheets
