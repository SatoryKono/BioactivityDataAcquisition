# API Reference

This section is intentionally compact in navigation. It exposes maintained
landing pages and stable deep references, while deprecated placeholder leaves
stay outside primary nav until they contain real maintained content.

It is a **curated published reference surface**, not an autogenerated dump of
every symbol in `src/bioetl/**`. The canonical implementation remains the live
source tree; these pages summarize the seams maintainers and integrators are
expected to reason about directly.

## Scope And Layering

- `Domain` pages describe pure domain constructs and ports; they must not imply
  direct I/O ownership by the domain layer.
- `Application` pages describe orchestration services, lifecycle, checkpoints,
  and control flows over domain abstractions.
- `Infrastructure` pages document concrete adapters, writers, HTTP clients, and
  persistence implementations.
- `Composition` remains the only DI/root assembly surface.
- Control-plane contracts that operators use directly belong primarily to
  [Contracts](../contracts/README.md), [CLI](../cli.md), and the linked
  runbooks, not to repo-only planning artifacts.

## What This Section Does Not Publish

- `docs/plans/**`, `docs/reports/**`, and `docs/99-archive/**` are repo-only or
  archive context, not API reference.
- Historical compatibility summaries may remain published elsewhere, but this
  index should point to the current layer/package entrypoints first.

## Docs-as-Code Policy

- Dependency-map drift is validated in CI and pre-commit via
  `scripts/engineering/qa/generate_architecture_dependency_map.py --check`.
- Generated architecture dependency artifacts are stored in:
  - `docs/02-architecture/generated/module-dependency-map.md`
  - `docs/02-architecture/generated/module-dependency-map.json`
- The JSON summary section contains two coupling metrics:
  - `cross_layer_group_edges` — top-60 slice used in the markdown table.
- `cross_layer_group_edges_total` — full graph count before slicing; enforced by `test_cross_layer_group_edges_total_budget` with the current reviewed ratchet baseline and budget set to `334`.
