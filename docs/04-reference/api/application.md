# Application Layer API Reference

> Autogenerated from source code. Layer overview: [Application Layer](../../02-architecture/02-application-layer.md)

The Application layer implements use-case orchestration for ETL pipelines. It contains
pipeline definitions, transformers, batch processing logic, data quality services, and
composite pipeline coordination. It depends on the Domain layer and is consumed by
Composition and Interfaces layers.

---
