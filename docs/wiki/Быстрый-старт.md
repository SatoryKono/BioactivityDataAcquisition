# Быстрый старт

Руководство по установке, настройке и первому запуску BioETL.

---

## Предварительные требования

| Компонент | Требование | Примечание |
|-----------|-----------|------------|
| **Python** | 3.11+ | Обязательно |
| **Make** | Любая версия | Для автоматизации команд |
| **uv** | Рекомендуется | Быстрый менеджер пакетов ([установка](https://docs.astral.sh/uv/getting-started/installation/)) |
| **Docker** | Опционально | Только для extras (Neo4j, мониторинг); не требуется для основного запуска |
| **Node.js** | Опционально | Для рендеринга Mermaid-диаграмм и инструментов документации |

## Установка

### Вариант A: через Make (рекомендуемый)

```bash
git clone https://github.com/SatoryKono/BioactivityDataAcquisition.git
cd BioactivityDataAcquisition
make install
make test-deps
make setup-plugins
```

- `make install` — использует `uv sync --extra dev --extra tracing` при наличии uv; иначе создаёт `.venv` и устанавливает пакет с dev-зависимостями
- `make test-deps` — проверяет наличие необходимых зависимостей для тестов
- `make setup-plugins` — настраивает плагины pytest и pre-commit хуки

### Вариант B: ручная установка через uv

```bash
git clone https://github.com/SatoryKono/BioactivityDataAcquisition.git
cd BioactivityDataAcquisition

# Основная установка
uv sync --extra dev --extra tracing

# С документацией (если нужен MkDocs)
uv sync --extra dev --extra tracing --extra docs
```

### Вариант C: ручная установка через pip

```bash
git clone https://github.com/SatoryKono/BioactivityDataAcquisition.git
cd BioactivityDataAcquisition

python3 -m venv .venv
. .venv/bin/activate
pip install -e ".[dev,tracing,docs]"
```

### Windows + WSL

При использовании одной копии репозитория из Windows PowerShell и WSL необходимо создавать раздельные виртуальные окружения:

```powershell
# Windows PowerShell
.\scripts\engineering\dev\setup_env_windows.ps1
```

```bash
# WSL/Linux
bash scripts/engineering/dev/setup_env_wsl.sh
```

Результат:

| Окружение | Путь |
|-----------|------|
| Windows PowerShell | `.venv-win` |
| WSL/Linux | `$HOME/.venvs/bioetl` (по умолчанию) |

## Настройка окружения

### Файл `.env`

Скопируйте шаблон и настройте API-ключи при необходимости:

```bash
cp .env.example .env
```

Секреты следуют паттерну `BIOETL_{PROVIDER}_{KEY}`. Для локальной разработки значения по умолчанию обычно достаточны.

### Основные переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|-------------|
| `BIOETL_ENV` | Среда (`dev` / `staging` / `prod`) | `dev` |
| `BIOETL_DATA_DIR` | Базовая директория для данных Bronze/Silver/Gold | `data` |
| `BIOETL_DEBUG` | Включить отладочные функции | `false` |
| `BIOETL_TEST_MODE` | Использовать фикстуры вместо реальных API | `false` |

Полный список переменных — на странице [[Конфигурация]].

## Запуск пайплайнов

### Активация окружения

```bash
# WSL/Linux
source "${BIOETL_WSL_VENV_DIR:-$HOME/.venvs/bioetl}/bin/activate"
```

```powershell
# Windows PowerShell
.\.venv-win\Scripts\Activate.ps1
```

### Примеры команд CLI

```bash
# Инкрементальное обновление для ChEMBL Activity
python -m bioetl run --pipeline chembl_activity --run-type incremental

# Полная загрузка с возможностью возобновления
python -m bioetl run --pipeline chembl_activity --run-type backfill --resume

# Инспекция карантинных записей
python -m bioetl quarantine inspect --pipeline chembl_activity --limit 10

# Список чекпоинтов
python -m bioetl checkpoint list --pipeline chembl_activity

# Запуск с ограничением количества записей
python -m bioetl run --pipeline chembl_publication --limit 50000
```

### Запуск без активации окружения

```bash
# Linux/WSL
"${BIOETL_WSL_VENV_DIR:-$HOME/.venvs/bioetl}/bin/python" -m bioetl run --pipeline chembl_publication --limit 50000
```

```powershell
# Windows PowerShell
.\.venv-win\Scripts\python.exe -m bioetl run --pipeline chembl_publication --limit 50000
```

## Локальное хранилище

BioETL использует **локальное файловое хранилище** по умолчанию (директория `data/`). Docker и внешние сервисы не требуются для основной работы. Подробнее — в [ADR-010](https://github.com/SatoryKono/BioactivityDataAcquisition/blob/main/docs/02-architecture/decisions/ADR-010-local-only-deployment.md).
