# Wiki-страницы BioETL

Эта директория содержит исходные файлы для [GitHub Wiki](https://github.com/SatoryKono/BioactivityDataAcquisition/wiki) проекта BioETL.

## Содержание

| Файл | Описание |
|------|----------|
| `Home.md` | Главная страница вики |
| `Архитектура.md` | Гексагональная архитектура (Ports & Adapters) с DDD |
| `Medallion-архитектура-данных.md` | Трёхуровневый поток данных (Bronze → Silver → Gold) |
| `Провайдеры-данных.md` | Поддерживаемые источники данных |
| `Быстрый-старт.md` | Установка, настройка и запуск |
| `Доменный-слой.md` | DDD-паттерны в доменном слое |
| `Тестирование.md` | Стратегия и инструменты тестирования |
| `Конфигурация.md` | Переменные окружения и YAML-конфигурации |
| `ADR-реестр.md` | Реестр архитектурных решений |

## Развёртывание

1. Инициализируйте Wiki через GitHub UI: создайте пустую Home-страницу на
   https://github.com/SatoryKono/BioactivityDataAcquisition/wiki/_new
2. Запустите скрипт из корня репозитория:

```bash
bash docs/wiki/deploy_wiki.sh
```
