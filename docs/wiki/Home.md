# BioETL: Фреймворк для сбора данных о биоактивности

> **Версия:** 6.1.0 | **Python:** 3.11+ | **Лицензия:** MIT

**BioETL** — это надёжный масштабируемый фреймворк для сбора, нормализации и обработки данных о биоактивности из крупнейших публичных баз данных (ChEMBL, PubChem, UniProt и др.) в единое аналитическое хранилище на основе **Delta Lake**.

---

## Оглавление

1. [[Архитектура]] — гексагональная архитектура (Ports & Adapters) с DDD
2. [[Medallion-архитектура-данных]] — трёхуровневый поток данных (Bronze → Silver → Gold)
3. [[Провайдеры-данных]] — поддерживаемые источники данных и их параметры
4. [[Быстрый-старт]] — установка, настройка и запуск пайплайнов
5. [[Доменный-слой]] — DDD-паттерны: порты, агрегаты, объекты-значения, сущности, схемы
6. [[Тестирование]] — стратегия тестирования, инструменты, команды
7. [[Конфигурация]] — переменные окружения, YAML-конфигурации, профили нормализации
8. [[ADR-реестр]] — реестр архитектурных решений (Architecture Decision Records)

## Ключевые особенности

- **Medallion Architecture** (медальонная архитектура) — структурированный поток данных через слои Bronze → Silver → Gold с контролем качества на каждом этапе
- **Delta Lake** — ACID-транзакции, контроль схем, возможность «путешествия во времени» (time travel)
- **Гексагональная архитектура** (Hexagonal Architecture / Ports & Adapters) — изоляция бизнес-логики от внешних зависимостей
- **Устойчивость** — встроенные Circuit Breaker (автоматические размыкатели), экспоненциальный backoff, Dead-Letter Queue (карантин)
- **Локальный запуск** — работа без внешних сервисов: in-memory блокировки, локальное хранилище файлов
- **Observability** (наблюдаемость) — порты для метрик (Prometheus), трассировки (OpenTelemetry) и логирования
- **Детерминированные записи** — воспроизводимые результаты и детерминированные повторные попытки
- **Плоскость управления** (Run Control Plane) — неизменяемые манифесты запусков и append-only реестры для отслеживания происхождения данных
- **Унифицированный HTTP-клиент** — стандартизированное ограничение частоты запросов (rate limiting), повторные попытки и телеметрия
