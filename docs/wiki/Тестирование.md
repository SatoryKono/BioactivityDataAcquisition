# Тестирование

BioETL использует многоуровневую стратегию тестирования с покрытием кода не менее 85%.

---

## Типы тестов

| Тип | Описание | Маркер pytest |
|-----|----------|---------------|
| **Unit** | Быстрые тесты без I/O, проверяют изолированную логику | `unit` |
| **Integration** | Тесты с I/O, используют VCR-кассеты для записанных HTTP-взаимодействий | `integration` |
| **Architecture** | Проверяют архитектурные границы слоёв и контракты | `architecture` |
| **E2E** | Сквозные тесты, могут требовать Docker | `e2e` |
| **Contract** | Контрактные тесты — стабильность API и схем | `contracts` |
| **Performance** | Тесты производительности и регрессий | `performance` |
| **Security** | Тесты безопасности | `security` |
| **Smoke** | Быстрые проверки для локальной разработки | `smoke` |
| **Benchmark** | Бенчмарки (исключены из стандартных запусков) | `benchmark` |

---

## Основные команды

### Запуск через Make

```bash
# Все тесты
make test

# Только Unit-тесты (быстрые, без I/O)
make test-unit

# Интеграционные тесты (VCR-кассеты, без сети)
make test-integration

# Архитектурные тесты
make test-architecture
```

### Запуск через скрипты-обёртки

```bash
# Linux/WSL — автоматическая проверка и установка плагинов
bash scripts/engineering/dev/run_pytest.sh
```

```powershell
# Windows PowerShell
.\scripts\engineering\dev\run_pytest.ps1
```

### Запуск через pytest напрямую

```bash
# С uv
uv run python -m pytest tests --cov=src/bioetl --cov-report=term

# С активированным окружением
python -m pytest tests --cov=src/bioetl --cov-report=term

# Конкретный тип тестов
python -m pytest tests -m unit
python -m pytest tests -m integration
python -m pytest tests -m architecture

# Бенчмарки (отдельный запуск)
python -m pytest -p no:xdist -m benchmark
```

## Инструменты тестирования

| Инструмент | Назначение |
|------------|-----------|
| **pytest** | Фреймворк тестирования |
| **pytest-cov** | Измерение покрытия кода |
| **pytest-xdist** | Параллельный запуск тестов |
| **pytest-timeout** | Таймаут для предотвращения зависаний (60 сек по умолчанию) |
| **pytest-asyncio** | Поддержка асинхронных тестов |
| **VCR.py** (pytest-vcr) | Запись и воспроизведение HTTP-взаимодействий (кассеты) |
| **Hypothesis** | Property-based тестирование (генеративные тесты) |
| **respx** | Мок HTTP-запросов для httpx |
| **syrupy** | Snapshot-тестирование |

## Маркеры тестов

Полный список маркеров, определённых в `pyproject.toml`:

- `unit` — Unit-тесты (быстрые, без I/O)
- `integration` — интеграционные тесты (могут использовать I/O)
- `e2e` — сквозные тесты (медленные, требуют Docker)
- `asyncio` — асинхронные тесты (pytest-asyncio)
- `slow` — медленные тесты (Hypothesis, длительные)
- `hypothesis` — property-based тесты
- `security` — тесты безопасности
- `vcr` — тесты с записанными HTTP-взаимодействиями
- `performance` — тесты производительности
- `architecture` — архитектурные тесты
- `contracts` — контрактные тесты
- `benchmark` — бенчмарки
- `smoke` — smoke-тесты
- `serial` — тесты, выполняемые последовательно (не параллелятся)
- `no_api` — тесты без внешнего доступа к API

Провайдер-специфичные маркеры: `uniprot`, `crossref`, `openalex`, `semanticscholar`.

---

## Покрытие кода

- Минимальное требование: **≥85%**
- Конфигурация: `pyproject.toml` (секция `[tool.coverage]`)
- Источник: `src/bioetl`
- Branch coverage включён

## Качество кода

```bash
# Линтинг и форматирование
make lint          # Только проверка
make lint-fix      # Автоисправление

# Проверка типов
make typecheck     # Строгий mypy

# Проверка сложности кода
make complexity
```
