# NCI Calibration Examples

This is a lightweight calibration reference for example patterns named by the skill.
Use these cases to orient scoring, not to produce canned verdicts.

## Example Set

| Case                             | Indicative Score | Why It Matters                                                                      |
| -------------------------------- | ---------------: | ----------------------------------------------------------------------------------- |
| Nayirah Testimony (1990)         |            `~88` | high emotional manipulation, urgency, and later contradiction of the core narrative |
| Tobacco Industry Denial Campaign |            `~82` | coordinated messaging, cherry-picking, and authority manipulation                   |
| Modern viral panic narrative     |          `50-70` | often combines urgency, tribal framing, and missing context                         |

## How To Use This File

- Compare pattern density, not subject matter.
- Prefer category-by-category alignment over raw score matching.
- If the current artifact is substantially different, use the examples only as rough anchors.
