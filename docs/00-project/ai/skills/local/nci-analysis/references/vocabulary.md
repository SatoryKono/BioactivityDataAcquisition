# Detection Vocabulary

Use this vocabulary as a prompting aid when scanning text for manipulation signals.

## Emotional Vocabulary

- fear, danger, threat, crisis, panic, shocking, outrageous

## Urgency Language

- now, immediately, urgent, before it is too late, last chance

## Tribal Markers

- we, they, us, them, real patriots, traitors, outsiders

## Dehumanizing Terms

- vermin, animals, horde, infestation, parasites

## Attribution Asymmetry Signals

- one side is "confirmed" while the other is only "claimed" or "alleged"

## Certainty Markers

- always, never, everyone knows, unquestionably, undeniably

Use vocabulary as a cue, not as proof on its own.
