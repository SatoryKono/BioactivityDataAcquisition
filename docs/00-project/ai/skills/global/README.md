# Global skill documentation snapshots

This tracked directory anchors the optional global-skill snapshot surface used
by the skills layout check in clean checkouts. No third-party skill snapshots
are currently committed here. Installed machine-local skills are discovered
from the active runtime catalogue and are not copied into the repository by CI.

Repository-local behavior is defined in `.codex/skills/` and the equal-peer
runtime trees. See the [skills overview](../README.md) for ownership and mirror
rules. Adding a curated snapshot requires its provenance and applicable license;
this directory is documentation and cannot override a runtime contract.
