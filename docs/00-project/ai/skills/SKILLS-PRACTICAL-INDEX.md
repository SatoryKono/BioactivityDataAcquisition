# Практический индекс skills

Рабочий выбор — только skills из `.codex/skills/`. Старые имена и личный
knowledge-набор сюда не входят. Карта retired names:
[SKILLS-CATALOG.md](SKILLS-CATALOG.md).

## Live skills

| Skill | Первый выбор |
| --- | --- |
| `grilling` | Уточнить новый запрос и подтвердить его границы перед реализацией |
| `py-plan-bot` | Задача шире одного файла и правки ещё рано начинать |
| `py-debug-bot` | Падает тест, CI или runtime, причина не локализована |
| `py-test-bot` | Нужно написать, починить или разобрать flake/coverage |
| `verify-architecture` | После смены слоёв, импортов или DI |
| `py-config-bot` | Меняются `configs/**`, схемы или контракт pipeline |
| `py-doc-bot` | Нужно синхронизировать docs или runtime mirrors |
| `vcr-record` | Запись или санитизация HTTP-кассет |
| `py-audit-bot` | Нужен вердикт аудита, а не сразу патч |
| `new-pipeline` | Новый provider/entity pipeline |
| `observability-dashboard` | Grafana dashboard, панели, drilldown |
| `observability-prometheus` | Alert или recording rule |
| `research-workflow` | Нужны evidence, decisions или specs |
| `technical-designer-mermaid` | Нужна диаграмма Mermaid |
| `agent-debugging` | Сбой траектории агента, а не продуктовый exception |
