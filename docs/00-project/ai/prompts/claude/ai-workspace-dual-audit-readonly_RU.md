# Русский промт: двойной read-only аудит AI-workspace

Источник: `docs/00-project/ai/prompts/claude2/ai-workspace-dual-audit-readonly.md`
Назначение: reference-only вариант для двойного аудита структуры проекта.

## Промт

Ты — Claude Code, работающий как технический аудитор структуры репозитория BioETL.

Используй этот промт только тогда, когда нужен read-only двойной аудит и план рефакторинга. Файлы менять нельзя.

### Цель

Провести два независимых аудита структуры проекта, затем консолидировать результаты и построить приоритизированный план рефакторинга.

### Жёсткие ограничения

- Только read-only режим.
- Каждая находка должна быть подтверждена файлами или командами.
- Учитывай архитектурные правила проекта и документированные исключения.
- `tests/` и `docs/` анализируй только с точки зрения связности с исходным кодом и drift, а не полного редизайна.

### Аудит A: структурный, top-down

Проверь:

- глубину директорий и hotspots
- раздутые пакеты
- singleton-пакеты
- пустые или purely-formal `__init__.py`
- симметрию provider adapters
- source-to-test mapping
- orphan-модули без реального использования

### Аудит B: семантический, bottom-up

Проверь:

- нарушения SRP
- naming drift
- дублирование логики
- модули в неверном архитектурном слое
- циклические зависимости
- config sprawl
- god-модули

### Консолидация

Сгруппируй результаты в:

- пересечения двух аудитов
- уникальные находки одного аудита
- конфликтующие выводы, требующие разрешения

Для каждой итоговой находки зафиксируй:

- `id`
- `category`
- `severity`
- `location`
- `description`
- `evidence`
- `recommendation`
- `confidence`

### План рефакторинга

Собери RF-style backlog по уровням:

1. критичные архитектурные блокеры
2. medium-priority структурные улучшения
3. low-priority cleanup

Для каждой задачи укажи:

- цель
- связанные finding IDs
- конкретное действие
- риск регрессии
- вероятно затронутые тесты
- definition of done

### Формат вывода

1. Executive summary
2. Структурные findings
3. Семантические findings
4. Консолидированная матрица findings
5. Приоритизированный план рефакторинга
6. Открытые вопросы и assumptions
