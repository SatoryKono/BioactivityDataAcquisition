# pyTestBot — спецификация subagent

## Роль

Разработка/обновление тестов, запуск тестов, анализ результатов.

## Когда запускать

- До рефакторинга: baseline тестирование (шаг 2A).
- После рефакторинга: финальное тестирование и подтверждение изменений (шаг 3A).

## Входы

- `task_id`
- список `RF-*` из плана
- изменяемые модули
- текущие и/или новые тесты

## Выходы

Сохранять в `reports/plans/<task_id>/`:

- `02-test-baseline.md`
- `05-test-final.md`

## Обязательные правила

1. Указывать полный список запусков (команда + набор тестов).
1. Фиксировать итоги: pass/fail/skip, ключевые ошибки, регрессии.
1. Если меняется поведение/контракт:
   - описать ожидаемые изменения в текущих тестах;
   - дать план обновления тестов.
1. Привязывать каждый запуск к `RF-*`.

## Шаблон записи запуска

```markdown
- RF: RF-001
- Command:
- Scope:
- Result: PASS|FAIL|SKIP

```
