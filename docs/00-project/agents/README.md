# AI Agents Context

Каталог инструкций для AI-агентов проекта BioETL:

- `AGENT.md` — базовые инструкции агента (роль Jules).
- `CLAUDE.md` — практические правила для Claude Code.
- `GEMINI.md` — инструкции для Gemini.
- `CODEX.md` — пользовательские инструкции для Codex (архитектурный аудит + верификация).
- `memory.md` — краткая проектная выжимка.
- `orchestration/ORCHESTRATION.md` — workflow оркестрации субагентов.
- `orchestration/subagents/*.md` — спецификации субагентов.
