## 2026-11-10 - Polars iter_rows vs to_dicts
**Learning:** Replacing `df.iter_rows(named=True)` with `df.to_dicts()` in Polars ETL pipelines is an anti-pattern. While `to_dicts()` is faster at constructing the dictionaries (using Rust instead of repeated Python context-switching), it materializes the entire DataFrame into a list of Python dictionaries at once. In a data engineering context where DataFrames hold millions of rows, this causes severe memory regressions (Out-Of-Memory errors).
**Action:** Avoid trading a CPU bottleneck (generator iteration) for a severe memory bottleneck. A true performance optimization in Polars must eliminate the Python loop entirely by using vectorized Polars expressions (e.g., `df.filter(...).height`), rather than just swapping iteration methods.
