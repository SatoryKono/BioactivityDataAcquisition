    Domain Types¶

    Core domain types and value objects.

    Identifiers¶

    RunID¶

    Unique identifier for a pipeline run (UUID).

    bioetl.domain.types.RunID = NewType('RunID', UUID) module-attribute ¶

    Unique identifier for a pipeline run (correlation ID).

    EntityID¶

    Business key for an entity (e.g., 'CHEMBL123').

    bioetl.domain.types.EntityID = NewType('EntityID', str) module-attribute ¶

    Business key for an entity (e.g., 'CHEMBL123', 'pubchem:2244').

    ContentHash¶

    SHA256 hash of canonical record representation.

    bioetl.domain.types.ContentHash = NewType('ContentHash', str) module-attribute ¶

    SHA256 hash of canonical record representation for versioning.

    BatchID¶

    Unique identifier for a data batch.

    bioetl.domain.types.BatchID = NewType('BatchID', UUID) module-attribute ¶

    Unique identifier for a data batch.

    Enums¶

    RunType¶

    Type of pipeline run (incremental, backfill, rebuild).

    bioetl.domain.types.RunType ¶

    Bases: str, Enum

    Type of pipeline run (RULES.md §2.4).

    Determines merge priority: REBUILD > BACKFILL > INCREMENTAL

    BACKFILL = 'backfill' class-attribute instance-attribute ¶

    Historical data backfill for specific date range.

    INCREMENTAL = 'incremental' class-attribute instance-attribute ¶

    Incremental load.

    REBUILD = 'rebuild' class-attribute instance-attribute ¶

    Full rebuild of all data (highest priority).

    priority() ¶

    Return numeric priority for conflict resolution.

    DriftLevel¶

    Schema drift severity levels.

    bioetl.domain.types.DriftLevel ¶

    Bases: str, Enum

    Schema drift severity levels (RULES.md §2.2).

    • INFO: New optional fields appear
    • WARN: >3 new fields appear
    • CRITICAL: Required fields (ID) disappear

    CRITICAL = 'CRITICAL' class-attribute instance-attribute ¶

    Critical drift (missing required fields), blocks pipeline.

    INFO = 'INFO' class-attribute instance-attribute ¶

    New optional fields detected (logged).

    WARN = 'WARN' class-attribute instance-attribute ¶

    Significant drift detected (>3 fields), requires review within 48h.

    HealthStatus¶

    Provider health status.

    bioetl.domain.types.HealthStatus ¶

    Bases: str, Enum

    Provider health status (RULES.md §3.5).

    State transitions: - HEALTHY → DEGRADED (1-2 errors) - DEGRADED → UNHEALTHY (≥3 errors) - UNHEALTHY → DEGRADED (1 successful health check) - DEGRADED → HEALTHY (0 errors for 5min)

    DEGRADED = 'DEGRADED' class-attribute instance-attribute ¶

    Provider experiencing issues (1-2 errors). Timeout x2, batch_size ÷2.

    HEALTHY = 'HEALTHY' class-attribute instance-attribute ¶

    Provider is operational (0 errors).

    UNHEALTHY = 'UNHEALTHY' class-attribute instance-attribute ¶

    Provider is down (≥3 errors). Pipeline paused, alert P2.

    to_metric_value() ¶

    Convert to numeric value for Prometheus metric.

    CircuitBreakerState¶

    Circuit breaker state machine states.

    bioetl.domain.types.CircuitBreakerState ¶

    Bases: str, Enum

    Circuit breaker state (RULES.md §3.1.4).

    State machine: - CLOSED: Normal operation - OPEN: Service unavailable (5 consecutive errors) - HALF_OPEN: Testing recovery (1 probe request after timeout)

    CLOSED = 'CLOSED' class-attribute instance-attribute ¶

    Circuit is closed, requests pass through.

    HALF_OPEN = 'HALF_OPEN' class-attribute instance-attribute ¶

    Circuit is testing recovery (1 probe request allowed).

    OPEN = 'OPEN' class-attribute instance-attribute ¶

    Circuit is open, requests are blocked (failure threshold reached).

    to_metric_value() ¶

    Convert to numeric value for Prometheus metric.

    DataClassification¶

    Data sensitivity classification.

    bioetl.domain.types.DataClassification ¶

    Bases: str, Enum

    Data sensitivity classification (RULES.md §5.4).

    INTERNAL = 'INTERNAL' class-attribute instance-attribute ¶

    Internal use only, not for public distribution.

    PUBLIC = 'PUBLIC' class-attribute instance-attribute ¶

    Publicly available data, no restrictions.

    RESTRICTED = 'RESTRICTED' class-attribute instance-attribute ¶

    Contains PII or sensitive data, requires encryption/hashing.

    ErrorType¶

    Error classification for handling strategy.

    bioetl.domain.types.ErrorType ¶

    Bases: str, Enum

    Error classification (RULES.md §3.1.1).

    Determines pipeline behavior: - CRITICAL: Fail pipeline immediately - RECOVERABLE: Retry with exponential backoff - DATA_QUALITY: Log and skip record (quarantine)

    AUTH_FAILURE = 'AUTH_FAILURE' class-attribute instance-attribute ¶

    API authentication failed (401, 403).

    DATA_QUALITY = 'DATA_QUALITY' class-attribute instance-attribute ¶

    General data quality error (e.g. thresholds).

    DB_UNAVAILABLE = 'DB_UNAVAILABLE' class-attribute instance-attribute ¶

    Database connection failed.

    INVALID_DATA = 'INVALID_DATA' class-attribute instance-attribute ¶

    Invalid data format (e.g., malformed SMILES).

    LOCK_LOST = 'LOCK_LOST' class-attribute instance-attribute ¶

    Distributed lock lost during execution.

    MISSING_REQUIRED_FIELD = 'MISSING_REQUIRED_FIELD' class-attribute instance-attribute ¶

    Required field is missing or null.

    NETWORK_ERROR = 'NETWORK_ERROR' class-attribute instance-attribute ¶

    Network connectivity issue.

    RATE_LIMIT = 'RATE_LIMIT' class-attribute instance-attribute ¶

    API rate limit exceeded (429).

    SCHEMA_EVOLUTION = 'SCHEMA_EVOLUTION' class-attribute instance-attribute ¶

    Schema drift detected in Silver layer (new/removed fields).

    SCHEMA_MISMATCH_GOLD = 'SCHEMA_MISMATCH_GOLD' class-attribute instance-attribute ¶

    Gold layer schema validation failed (strict mode).

    SCHEMA_VIOLATION = 'SCHEMA_VIOLATION' class-attribute instance-attribute ¶

    Record failed schema validation.

    TIMEOUT = 'TIMEOUT' class-attribute instance-attribute ¶

    Request timeout (502, 504).

    is_critical() ¶

    Check if error should fail pipeline.

    is_data_quality() ¶

    Check if error is data quality issue (skip record).

    is_recoverable() ¶

    Check if error should be retried.

    DQStatus¶

    Quarantine record status.

    bioetl.domain.types.DQStatus ¶

    Bases: str, Enum

    Quarantine record status (RULES.md §2.6).

    IGNORED = 'IGNORED' class-attribute instance-attribute ¶

    Reviewed and marked as non-actionable.

    NEW = 'NEW' class-attribute instance-attribute ¶

    Newly quarantined record, needs triage.

    REPROCESSED = 'REPROCESSED' class-attribute instance-attribute ¶

    Successfully reprocessed and moved to Silver.

    Single configuration validation error.

    Used by PreflightService to report Medallion invariant violations.

    Name Type Description

    Configuration field path that failed validation.
    expected str

    Expected value or constraint description.
    actual str

    Actual value found in configuration.
    rule str

    Reference to RULES.md section defining this constraint.

    Result of a single component health check.

    bioetl.domain.types.ComponentHealthResult dataclass ¶

    Result of a single component health check.

    Attributes:

    Name Type Description
    component str

    Name of the component (e.g., 'storage', 'data_source').
    status HealthStatus

    Health status of the component.
    duration_seconds float

    Time taken to perform the health check.
    error_message str | None

    Optional error message if check failed.

    HealthReport¶

    Aggregated health check report.

    bioetl.domain.types.HealthReport dataclass ¶

    Aggregated health check report.

    Attributes:

    Name Type Description
    results list[ComponentHealthResult]

    List of individual component health results.
    checked_at datetime

    Timestamp when checks were performed.

    is_healthy property ¶

    Return True if all critical components are healthy.

    overall_status property ¶

    Return worst status among all components.

    get_failures() ¶

    Return list of components with UNHEALTHY status.

    PreflightReport¶

    Preflight validation report.

    bioetl.domain.types.PreflightReport dataclass ¶

    Preflight validation report.

    Aggregates results from infrastructure health checks and medallion policy validation.

    Attributes:

    Name Type Description
    health_report HealthReport

    Infrastructure health check results.
    medallion_policy_valid bool

    True if config is compatible with policy.
    config_errors list[ConfigValidationError]

    List of configuration validation errors.
    checked_at datetime

    Timestamp when validation was performed.

    is_valid property ¶

    Return True if all validations passed.

    should_block_startup property ¶

    Return True if validation failures should block pipeline startup.

    Usage Example¶

    from bioetl.domain.types import RunType, HealthStatus

# Using enums
run_type = RunType.INCREMENTAL
status = HealthStatus.HEALTHY

# Using NewType
from uuid import uuid4
run_id = RunID(uuid4())
