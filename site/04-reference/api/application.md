# Application Layer

Слой приложения отвечает за оркестрацию пайплайнов и выполнение сценариев обработки данных.

## Ключевые компоненты

### PipelineRunner

Управляет жизненным циклом выполнения пайплайна, координирует блокировки, чекпоинты и запуск исполнения, делегируя специализированные операции сервисам preflight, postrun и медальонной политики.

### BatchExecutor

Единый исполнитель батчей ETL: извлечение → трансформация → запись с трассировкой; объединяет извлечение, трансформацию и запись, поддерживает адаптивный размер батча, чекпоинты и graceful shutdown.

### RecordProcessor

Оркестрирует трансформацию и запись батчей по всем слоям.

### PipelineServices

Пакет внедряемых зависимостей, типизированных через Protocol для тестируемости; frozen dataclass предотвращает замену сервисов во время выполнения.

### PreflightService

Проводит валидацию инфраструктуры перед запуском пайплайна: health-checks, проверку конфигурации медальонных слоёв и политики режима записи.

### PostrunService

Выполняет пост-операции: DQ-проверки, генерацию DQ-отчётов (при наличии сервиса), VACUUM и очистку трассировщика.
