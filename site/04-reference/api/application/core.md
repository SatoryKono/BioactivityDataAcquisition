# Application Core

Раздел описывает базовые компоненты исполнения пайплайнов, сформированные из docstring’ов модулей и классов.

## PipelineRunner

Управляет жизненным циклом выполнения пайплайна, координирует блокировки и чекпоинты, оставаясь отделённым от бизнес-логики самого пайплайна. Делегирует специализированные операции PreflightService, PostrunService и MedallionLifecycleService.

## BatchExecutor

Единый исполнитель батчей ETL: извлечение → трансформация → запись с трассировкой. Объединяет извлечение, трансформацию и запись в один компонент и поддерживает адаптивный размер батча, чекпоинты и graceful shutdown.

### BatchResult

Результат обработки батча с количеством записей в Bronze/Silver/Gold и количеством записей в карантине.

## RecordProcessor

Оркестрирует трансформацию батчей и запись по всем слоям.

## PipelineServices

Набор внедряемых зависимостей для выполнения пайплайна. Все поля типизированы через Protocol, а frozen dataclass предотвращает случайную замену сервисов в ходе выполнения.

## PreflightService

Проверяет инфраструктуру перед запуском пайплайна: health-checks, валидацию конфигурации медальонных слоёв и политики режимов записи.

## PostrunService

Выполняет пост-операции: DQ-проверки через DataQualityService, генерацию DQ-отчётов через DQReportService (при наличии), VACUUM через MedallionLifecycleService и очистку трассировщика.

## CheckpointManager

Фреймворк-независимый менеджер чекпоинтов для хранения прогресса выполнения.

## LockManager

Управляет получением, освобождением и поддержанием распределённых блокировок, включая heartbeat и контекст блокировки для writers.

## QuarantineManager

Записывает проблемные записи в карантин для последующего анализа и возможной переработки.

## MemoryConfig

Конфигурация для обработки батчей с учётом использования памяти (порог давления, минимальный размер батча, интервал проверок).

## MemoryMonitor

Отслеживает потребление памяти и рекомендует адаптивный размер батча для предотвращения OOM.

## ShutdownSignal

Общий сигнал для координации graceful shutdown; реализует ShutdownPort и может использоваться как совместимая замена ShutdownService.

## PipelineShutdownError

Исключение, сигнализирующее о запросе корректного завершения пайплайна с сохранением чекпоинта.

## CleanupService

Единый сервис очистки Silver/Gold слоёв с режимом preview и фактическим удалением данных.

### CleanupPreview

Результат предварительного просмотра очистки с информацией о слоях и общем числе файлов.

### CleanupResult

Результат очистки с количеством удалённых элементов по слоям и признаком dry-run.
