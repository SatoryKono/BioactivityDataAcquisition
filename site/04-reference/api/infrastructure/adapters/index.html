    HTTP Adapters¶

    UnifiedHTTPClient¶

    Unified HTTP client with rate limiting, circuit breaker, and observability.

    bioetl.infrastructure.adapters.http.client.UnifiedHTTPClient dataclass ¶

    Async HTTP client with rate limiting, circuit breaker, and observability.

    Coordinates HTTP communication using injected resilience and observability components (SRP-compliant design).

    Observability (Phase 1 Refactoring): - Creates tracing spans for all HTTP requests with method/URL/status attributes - Records http_request_duration_seconds histogram by provider/method/status - Increments http_request_errors_total counter on failures - Logs circuit breaker state changes and retry attempts

    Parameters:

    Name Type Description Default
    rate_limiter RateLimiterPort

    RateLimiterPort implementation for rate limiting

    		 required
    circuit_breaker CircuitBreakerPort

    CircuitBreakerPort implementation for fault tolerance

    		 required
    retry_policy RetryPolicy

    RetryPolicy for exponential backoff configuration

    		 RetryPolicy()
    timeout float

    Request timeout in seconds (default: 30.0)

    		 30.0
    run_id RunID | None

    Current run ID for correlation header

    		 None
    user_agent str

    User-Agent string (default: "BioETL/5.0.0")

    		 'BioETL/5.0.0'
    contact_email str | None

    Optional contact email to append to User-Agent

    		 None
    provider str

    Provider name for metrics labels (default: "unknown")

    		 'unknown'
    tracer TracingPort | None

    TracingPort for distributed tracing (default: NoOpTracing)

    		 None
    metrics MetricsPort | None

    MetricsPort for metrics collection (default: NoOpMetrics)

    		 None
    logger LoggerPort | None

    LoggerPort for structured logging (optional)

    		 None
    Example

    from bioetl.infrastructure.adapters.http import TokenBucket, CircuitBreaker bucket = TokenBucket(rate=5.0, capacity=5) cb = CircuitBreaker(provider="chembl") client = UnifiedHTTPClient(rate_limiter=bucket, circuit_breaker=cb) async with client: ... response = await client.get("https://api.example.com/data")

    TokenBucket¶

    Token bucket rate limiter implementation.

    bioetl.infrastructure.adapters.http.rate_limiter.TokenBucket dataclass ¶

    Async token bucket rate limiter.

    Implements the token bucket algorithm for rate limiting API requests. Tokens are replenished at a fixed rate up to a maximum capacity.

    Parameters:

    Name Type Description Default
    rate float

    Tokens added per second

    		 required
    capacity int

    Maximum tokens in bucket

    		 required
    Example

    bucket = TokenBucket(rate=5.0, capacity=10) # 5 req/sec, burst of 10 await bucket.acquire() # Wait for token await bucket.acquire(tokens=2) # Acquire multiple tokens

    Provider rate limits (from RULES.md Appendix A): - PubChem: 5 req/sec - UniProt: 100 req/sec (with API key) - OpenAlex: 10 req/sec (polite) - Crossref: 50 req/sec (polite) - Semantic Scholar: 100 req/5min = ~0.33 req/sec - PubMed: 3 req/sec (10 with API key)

    CircuitBreaker¶

    Circuit breaker pattern implementation.

    bioetl.infrastructure.adapters.http.circuit_breaker.CircuitBreaker dataclass ¶

    Circuit breaker implementation for HTTP clients.

    Protects against cascading failures by temporarily blocking requests to failing services.

    Parameters:

    Name Type Description Default
    provider str

    Provider name for metrics/logging

    		 required
    failure_threshold int

    Consecutive failures before opening (default: 5)

    		 5
    recovery_timeout int

    Seconds to wait in OPEN before testing (default: 300)

    		 300
    metrics MetricsPort | None

    Optional MetricsPort for emitting circuit breaker metrics

    		 None
    Example

    cb = CircuitBreaker(provider="chembl", failure_threshold=5) result = await cb.call(fetch_data, url="https://api.example.com")

    Metrics emitted
    • circuit_breaker_state{provider}: 0=Closed, 1=Half-Open, 2=Open
    • circuit_breaker_trips_total{provider}: Counter of OPEN transitions

    __init__(provider, failure_threshold=5, recovery_timeout=300, metrics=None) ¶

    DeltaWriter¶

    Storage adapter for Delta Lake (Silver/Gold layers).

    Writer for Silver layer (normalized data in Delta Lake).

    Implements merge/upsert strategy to handle updates and deduplication. CSV export is delegated to an optional CsvExporter (composition pattern).

    Usage Example¶

    from bioetl.infrastructure.adapters.http.client import UnifiedHTTPClient
from bioetl.infrastructure.adapters.http.rate_limiter import TokenBucket

# Create rate limiter
limiter = TokenBucket(rate=5.0, capacity=10)

# Create client
client = UnifiedHTTPClient(
    rate_limiter=limiter,
    provider="chembl",
)

# Make request
response = await client.get("https://www.ebi.ac.uk/chembl/api/data/activity")
