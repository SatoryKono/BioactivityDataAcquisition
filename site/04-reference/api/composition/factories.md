# Composition Factories

Раздел описывает фабрики композиционного слоя, собранные по docstring’ам.

## assemble_runner

Функция собирает полный граф исполнения пайплайна, используя единый BatchExecutor, который объединяет извлечение и обработку. Зависимости создаются напрямую внутри функции в соответствии с DI-подходом без промежуточного RunnerServices-бандла.
