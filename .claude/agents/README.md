# Claude Agent Surface Mirror

This directory is a compatibility mirror for tooling that still resolves
`.claude/agents/*` paths.

Canonical agent registry surfaces live here:

- `.codex/agents/README.md`
- `.codex/agents/ORCHESTRATION.md`
- `.codex/agents/CODEX-RUNTIME.md`

For Gemini-specific canonical sources, use `.gemini/agents/README.md`.

Repo-wide documentation audits route through the `documentation-audit` and
`documentation-cascade-audit` skills rather than a dedicated documentation-only
agent entry.
