# Codex WSL Setup (canonical)

Native Codex CLI runs inside WSL2 (Ubuntu/Debian). Docker/sbx is optional — see setup-codex-wsl.sh.

## Prerequisites

- Windows 10/11 with WSL2
- Ubuntu or Debian distro (default WSL distro is fine)
- OpenAI API key: https://platform.openai.com/api-keys

## Step 1: Install WSL (if missing)

PowerShell as Administrator:

    wsl --install

Reboot, then create a Linux user when Ubuntu starts.

Optional: pin a distro:

    setx BIOETL_WSL_DISTRO Ubuntu

## Step 2: One-time setup

From repo root (PowerShell):

    .\setup-codex-wsl.bat

Or:

    .\setup-codex-wsl.ps1

This installs Node.js, Codex CLI, and verifies Docker/proxy connectivity inside WSL.

## Step 3: API key

The setup script does not create `.env.codex` by default. Create it manually:

    copy scripts\ai\codex\.env.codex.example scripts\ai\codex\.env.codex
    notepad scripts\ai\codex\.env.codex

Add: OPENAI_API_KEY=sk-...

Or run setup with explicit opt-in to generate a local template:

    $env:BIOETL_CREATE_LOCAL_ENV_FILES="1"
    .\setup-codex-wsl.ps1

## Step 4: Launch Codex

Interactive (Windows):

    .\codex.ps1
    .\run-codex-wsl.ps1
    .\scripts\ops\codex.bat

With prompt (auto-exec):

    .\codex.ps1 exec "analyze the pipeline"
    .\scripts\ops\codex-exec.bat "fix the failing test"

Fast launch (skip MCP sync if setup hangs):

    .\scripts\ops\launchers\codex\codex-fast.bat

From WSL:

    bash scripts/ai/codex/run-codex.sh
    bash scripts/ai/codex/run-codex.sh exec "your prompt"

## Diagnostics

    .\scripts\ai\codex\run-codex.ps1 check
    .\scripts\ai\codex\diagnose_wsl.ps1
    wsl --list --verbose

## Troubleshooting

WSL not found:
    wsl --install

Codex CLI missing:
    .\scripts\ai\codex\run-codex.ps1 setup

MCP setup hangs:
    set CODEX_SKIP_MCP_SETUP=1
    Or use codex-fast.bat

API key missing:
    Create scripts\ai\codex\.env.codex from .env.codex.example
    Or rerun setup with: $env:BIOETL_CREATE_LOCAL_ENV_FILES="1"
