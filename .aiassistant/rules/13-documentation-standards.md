# Documentation Standards

> Scope:
> - USE WHEN writing or modifying documentation
> - Use when editing files matching: `docs/**/*.md`, `**/INDEX.md`, `**/README.md`

## SYNCHRONIZATION (MANDATORY)

- Documentation MUST be synchronized with code and schemas
- Any change to public contracts, ABCs, Default factories, Impl, or pipeline config MUST be reflected in docs in the same PR
- Breaking changes MUST be recorded in `CHANGELOG.md`

## AUTO-GENERATION

- Auto-generated sections MUST be marked: `<!-- generated -->`
- Auto-generated sections MUST NOT be edited manually
- Generator and timestamp MUST be recorded in autogenerated block

## PIPELINE DOCS

- Format: `NN-<entity>-<provider>-<topic>.md` in `docs/pipelines/<provider>/<entity>/`
- H1 heading MUST duplicate filename in Title Case
- Internal anchors from `##` headings in kebab-case
- Relative links MUST pass link-checker (`.lychee.toml`)

## NEW ENTITY DOCUMENTATION

When adding a new entity (contract/pipeline/client), PR MUST include:
1. Documentation under `docs/pipelines/<provider>/<entity>/` using `NN-<entity>-<provider>-<topic>.md`
2. Entry/update in `docs/ABC_INDEX.md` if ABC/contract is added
3. Updates to `abc_registry.yaml` and `abc_impls.yaml` when creating ABC/Default/Impl

## EXAMPLES

Valid:
- `docs/pipelines/chembl/activity/09-activity-chembl-extraction.md`
- `docs/pipelines/chembl/activity/10-activity-chembl-transformation.md`
- `docs/INDEX.md`
- `docs/pipelines/README.md`

Invalid:
- `docs/pipelines/chembl/activity/extraction.md` (missing NN- prefix)
- `docs/pipelines/Chembl/Activity/Extraction.md` (uppercase, underscores)
