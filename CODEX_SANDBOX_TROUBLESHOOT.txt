# Codex Setup for WSL - Docker Sandbox Error Troubleshooting

## Current Issue
```
panic: whp error, failed to set extended vm exits: The parameter is incorrect
```

This indicates Docker Desktop's virtualization layer (Windows Hypervisor Platform) has an issue.

## Solutions (in order)

### 1. Restart Docker Desktop
```powershell
# Quit Docker completely
taskkill /IM "Docker Desktop.exe" /F
taskkill /IM "com.docker.proxy.exe" /F
Start-Sleep -Seconds 5

# Restart Docker Desktop
Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"

# Wait 30 seconds for startup
Start-Sleep -Seconds 30

# Test
docker ps
```

### 2. Check Hyper-V / Virtualization
```powershell
# Check if Hyper-V is enabled
Get-WindowsOptionalFeature -Online -FeatureName Hyper-V

# If not enabled, enable it (requires admin + reboot)
Enable-WindowsOptionalFeature -Online -FeatureName Hyper-V -All

# Check CPU virtualization in BIOS
# Reboot and enter BIOS (usually Del or F2 key)
# Look for "VT-x" (Intel) or "AMD-V" (AMD) and enable it
```

### 3. Docker Desktop Settings
- Open Docker Desktop UI (Windows tray)
- Settings > General
- Check "Use containerd for pulling and storing images"
- Settings > Resources
- Increase Memory to 8GB+ (especially for Codex)
- Apply & Restart

### 4. WSL Integration
```powershell
# Ensure WSL 2 is active (not WSL 1)
wsl --list -v

# Output should show WSL 2 for your distribution

# If using WSL 1, upgrade:
wsl --set-version Ubuntu 2
```

### 5. Run Codex Directly (Docker Container, No Sandbox)
If sandbox VMs continue to fail, run Codex as a regular Docker container:

```powershell
# Pull the Codex Docker image
docker pull docker/sandbox-templates:codex

# Set OpenAI key
$env:OPENAI_API_KEY = "sk-your-key-here"

# Run Codex container
docker run -it --rm `
  -e OPENAI_API_KEY=$env:OPENAI_API_KEY `
  -v "$PWD:/workspace" `
  docker/sandbox-templates:codex `
  codex --dangerously-bypass-approvals-and-sandbox "/workspace"
```

### 6. Alternative: Use Docker Agent (if Codex unavailable)
```powershell
# Try Claude agent instead
docker sandbox run claude .

# Or use docker agent
docker agent --help
```

## If All Else Fails
Install `sbx` CLI manually and use it:
1. Download: https://github.com/docker/sbx/releases
2. Extract `sbx.exe` to `$env:LOCALAPPDATA\sbx\`
3. Add to PATH
4. Run: `sbx secret set -g openai --oauth`
5. Run: `sbx run codex .`
