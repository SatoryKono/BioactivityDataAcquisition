### ✅ Исправлено (Completed)

1.  **Устранение утечки инфраструктуры в Application (Priority 1):**
    *   Удален импорт `from bioetl.infrastructure.config import get_settings` из `src/bioetl/application/core/orchestrator.py`.

    *   Слой `Application` теперь полностью чист от инфраструктурных зависимостей (кроме интерфейсов/портов).

2.  **Унификация HTTP клиентов (Priority 2):**
    *   Реализован `PaginatedFetcherMixin` в `src/bioetl/infrastructure/adapters/http/pagination.py`.

    *   `ChemblAdapter` переписан на использование `PaginatedFetcherMixin` с offset-based пагинацией.
    *   Устранено дублирование кода обработки циклов `while True` и повторных запросов.
