Issue: "The term 'codex.bat' is not recognized"

Solution:
  ✓ Make sure you're in the correct directory
  ✓ Run from PowerShell, NOT cmd.exe
  ✓ Make sure ./scripts/ops/ directory exists

  Verify:
    ls .\scripts\ops\codex.bat


Issue: "wsl: Unknown distro"

Solution:
  Check your WSL distros:
    wsl --list --verbose

  Edit .\scripts\ops\setup-codex-wsl.bat and change:
    set "WSL_DISTRO=Ubuntu"
  to match your distro name (e.g., "Debian", "Ubuntu-20.04")


Issue: "Node.js not found"

Solution:
  Run setup again to install Node.js:
    .\scripts\ops\setup-codex-wsl.bat


Issue: "Docker Desktop not responding"

Solution:
  Make sure Docker Desktop is running:
  1. Open Docker Desktop app
  2. Wait for status icon to turn green
  3. Try again


Issue: "Network errors or timeout"

Solution:
  Start the proxy server:
    .\scripts\ops\start-wsl-proxy.bat

  Then try your command again


Issue: Proxy errors in WSL

Solution:
  From PowerShell:
    .\scripts\ops\start-wsl-proxy.bat

  Or manually enable proxy in WSL terminal:
    source ./.wsl_proxy_env.sh
