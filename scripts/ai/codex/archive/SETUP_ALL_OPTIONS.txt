================================================================================
OPTION 1: NO-SUDO SETUP (Recommended)
================================================================================

From PowerShell:
  .\scripts\ops\setup-codex-nosudo.ps1

What it does:
  ✓ Checks Node.js & npm
  ✓ Installs Codex CLI
  ✓ No sudo password required
  ✓ Takes 2-3 minutes

Prerequisites:
  • Node.js installed (check: node --version)

  1. Open WSL
  2. Run: sudo apt-get install -y nodejs npm

================================================================================
OPTION 2: MANUAL SETUP (Direct WSL)
================================================================================

Open WSL terminal and run:

  # Check Node.js
  node --version
  npm --version

  # If not found, install:
  sudo apt-get install -y nodejs npm

  # Install Codex
  mkdir -p ~/.cache/tools/codex-cli/npm-global
  export NPM_CONFIG_PREFIX=~/.cache/tools/codex-cli/npm-global
  npm install -g @openai/codex@latest

  # Test
  ~/.cache/tools/codex-cli/npm-global/bin/codex --version

  # Exit WSL
  exit

Then from PowerShell:
  .\scripts\ops\codex.bat "hello"

OPTION 3: FULL SETUP (Complete)
================================================================================

From PowerShell:
  .\scripts\ops\setup-codex-wsl.bat

What it does:

  ✓ Installs Node.js & npm
  ✓ Installs Codex CLI
  ✓ Configures proxy
  ✓ Verifies Docker Desktop

When prompted:

TROUBLESHOOTING
================================================================================

  → Use Option 1 (No-Sudo) instead
  → Or use Option 2 (Manual) and skip apt-get update

  → Open WSL
  → Run: sudo apt-get install -y nodejs npm
  → Run: node --version (verify)
  → Close WSL
  → Re-run setup

Setup hangs or times out:
  → Use Ctrl+C to stop it
  → Then use Option 2 (Manual) instead
  → Or use Option 1 (No-Sudo)

Codex command not found after setup:
  → Try again: npm install -g @openai/codex@latest
  → Or check: ls ~/.cache/tools/codex-cli/npm-global/bin/

Can't run scripts:
  → Make sure you're in PowerShell (not cmd.exe)
