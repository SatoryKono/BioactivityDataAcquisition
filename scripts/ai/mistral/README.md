# Mistral - Compatibility Alias

`scripts/ai/mistral` is a thin compatibility alias for the canonical local-model
launcher in `scripts/ai/mistrall`.

Use:

```bash
bash scripts/ai/mistral/run-mistral.sh daemon
bash scripts/ai/mistral/run-mistral.sh pull
bash scripts/ai/mistral/run-mistral.sh status
```

Or call the canonical surface directly:

```bash
bash scripts/ai/mistrall/run-mistrall.sh daemon
bash scripts/ai/mistrall/run-mistrall.sh pull
bash scripts/ai/mistrall/run-mistrall.sh status
```
