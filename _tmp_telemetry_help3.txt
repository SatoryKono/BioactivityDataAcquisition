usage: update_test_telemetry_baseline.py [-h] [--coverage-xml COVERAGE_XML]
                                         [--coverage-percent COVERAGE_PERCENT]
                                         [--coverage-log COVERAGE_LOG]
                                         [--slowest-json SLOWEST_JSON]
                                         [--junit JUNIT]
                                         [--output-yaml OUTPUT_YAML]
                                         [--output-md OUTPUT_MD]
                                         [--source-branch SOURCE_BRANCH]
                                         [--source-commit SOURCE_COMMIT]
                                         [--source-run-id SOURCE_RUN_ID]
                                         [--source-event {pull_request,push,workflow_dispatch,schedule}]
                                         [--source-run-url SOURCE_RUN_URL]
                                         [--coverage-threshold COVERAGE_THRESHOLD]

Materialize a committed telemetry baseline from coverage.xml and slowest-
tests.json, or from resilient CI diagnostics artifacts.

options:
  -h, --help            show this help message and exit
  --coverage-xml COVERAGE_XML
                        Path to coverage XML produced by coverage-verify.
  --coverage-percent COVERAGE_PERCENT
                        Explicit coverage percentage fallback when
                        coverage.xml is unavailable, for example when
                        reconstructing the baseline from CI diagnostics.
  --coverage-log COVERAGE_LOG
                        Optional log file containing a coverage report line
                        such as 'TOTAL ... 92.81%'. Used when coverage.xml is
                        unavailable.
  --slowest-json SLOWEST_JSON
                        Path to slow-test telemetry JSON produced by duration-
                        telemetry.
  --junit JUNIT         Optional JUnit XML path used to derive duration
                        telemetry when slowest-tests.json is unavailable. May
                        be passed multiple times.
  --output-yaml OUTPUT_YAML
                        Committed YAML baseline path.
  --output-md OUTPUT_MD
                        Committed Markdown baseline path.
  --source-branch SOURCE_BRANCH
                        Branch from which the telemetry baseline was captured.
  --source-commit SOURCE_COMMIT
                        Commit SHA or revision label for the captured
                        baseline.
  --source-run-id SOURCE_RUN_ID
                        CI run identifier associated with the captured
                        baseline.
  --source-event {pull_request,push,workflow_dispatch,schedule}
                        GitHub Actions event that produced the captured
                        artifacts.
  --source-run-url SOURCE_RUN_URL
                        Canonical GitHub Actions URL for the captured source
                        run.
  --coverage-threshold COVERAGE_THRESHOLD
                        Canonical hard coverage threshold enforced in CI.
