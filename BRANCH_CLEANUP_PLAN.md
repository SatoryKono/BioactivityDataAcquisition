## Рекомендации по дальнейшей очистке

### Удалённые ветки (origin/*)
Для очистки удалённых веток потребуется:

1. Проверить наличие открытых PR для каждой ветки
2. Удалить локальные ссылки на удалённые ветки:
   ```bash
   git branch -d -r origin/branch-name
   ```
3. Удалить ветки с удалённого сервера (требует прав):
   ```bash
   git push origin --delete branch-name
   ```

### Автоматизация
Рекомендуется настроить автоматическую очистку:
- Автоматическое удаление слитых веток после закрытия PR
- Периодическая очистка временных веток (tmp, test-*)
- Автоматическое удаление bot-веток после закрытия соответствующих issues
