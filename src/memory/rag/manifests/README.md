# RAG Manifests

This directory stores deterministic RAG corpus artifacts generated by:

```bash
python -m memory.rag.indexing --print-summary
```

Primary artifacts:

- `corpus_catalog.json`
- `chunks.jsonl`

The current MVP indexes markdown sources from:

- `docs/00-project/`
- `docs/02-architecture/decisions/`
- `docs/05-operations/runbooks/`

Archive and generated-report surfaces are excluded by policy.
