# Graph Projections

This directory is reserved for rebuild-only graph relation projections.
Generated files such as `file_references.jsonl` and
`module_references.jsonl` must not be committed. Expanded graph snapshots such
as `bioetl_knowledge_graph_expanded.json` and
`bioetl_knowledge_graph_expanded_compact.json` are also rebuild-only and must
remain untracked.
