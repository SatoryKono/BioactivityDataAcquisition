# Отчёт о технической приёмке (Issue #12366)

## 1. Сверка SHA и запусков
- Использованы исторические SHA без перепривязки к новому HEAD. Доказательства (evidence) собраны в `reports/quality/proof-or-stop/`.

## 2. Обязательные проверки и fail-closed
- Все обязательные проверки (smoke, security, architecture, E2E, unit) сохранены. Примеры независимых прогонов, подтверждающих корректный fail-closed при отсутствии нужных артефактов (например, #12364), зафиксированы.

## 3. Mypy equivalence и кэш
- Cold/warm mypy equivalence подтверждена в ходе #12361. Непреднамеренных Docker-дублей не выявлено (устранены в рамках #12474).

## 4. Расчёты before/after
- Точное суммарное job-time и время queue/execution не может быть достоверно стратифицировано без исходных billing-данных (status: AWAITING_DATA, см. #12351).

## 5. Целевая гипотеза R1
- Целевая гипотеза `T_checkout+setup_after < 0.5 * T_checkout+setup_before` **не достигнута** (отказ по #12361, оптимизация preflight-кэша признана no-go).

## 6. Полнота архивов
- Baseline и shadow архивы в наличии, retention/consumer windows соблюдаются, правила (ci-evidence-retention-policy.md) не нарушены. Ограничения retention для #12362 не выполнены, из-за чего заблокировано сокращение окон (Issue #12364).

## 7. Заключения
- **Корректность**: Технически пайплайны остаются консистентными, потери обязательных проверок нет.
- **Технический эффект**: Ограничен (из-за отказа от кэша).
- **Финансовый эффект**: "не установлен" (отсутствует billing-выгрузка по #12351).
- **Ограничения/Риски**: Residual trust risks остаются из-за отсутствия независимых billing-данных и невыполнения требований shadow-window (#12362).

## Критерии приёмки
- [x] Все принятые изменения имеют exact-SHA evidence (см. reports/quality/proof-or-stop/). Условные решения отражены (#12361, #12364).
- [x] Ни одна обязательная проверка не удалена/ослаблена.
- [x] Ограниченная приёмка явно согласована (из-за нехватки сопоставимых завершённых попыток).
- [x] Зафиксирована недостижимость целевой гипотезы и отсутствие wall-time регрессии.
- [x] Непреднамеренные Docker-повторы устранены.
- [x] Сырые данные в окне доказаны (кроме биллинга).
