# Визуальная приёмка Grafana: #10496–#10504

Повторная визуальная проверка семи основных дашбордов BioETL в тёмной теме,
при viewport 1920×1080 и 1600×900. Проверены первые экраны, раскрываемые
разделы, таблицы ниже первого экрана, фильтры и переходы. Снимки сделаны
в браузере; проверка JSON использована дополнительно для подтверждения
соответствия развёрнутой версии, а не вместо визуального просмотра.

Основное окно: 2026-09-16 03:00–15:00 UTC (06:00–18:00 EEST).
Workflow `chembl_baseline`, Pipeline `chembl_publication`, Run Type `backfill`,
Run ID `e9891e4f-32b7-500d-8b2b-3faaa1c211b4`; Stage/Provider `All`,
когда соответствующий фильтр присутствует. Дополнительная проверка счётчика
устаревших сущностей использует конец диапазона `now`, а финальная воспроизводимая
пара снимков — 2026-09-16 16:14:00 UTC, когда метрика присутствовала. Точный поиск Run Explorer
дополнительно задаёт тот же полный UUID в `Find exact Run ID`.

Исходная инспекция и 94 before-снимка опубликованы в
[родительской задаче #10433](https://github.com/SatoryKono/BioactivityDataAcquisition/issues/10433).
Исходный диапазон `Last 12 hours` был относительным, а SHA до исправлений не
фиксировался. Поэтому before/after сопоставляет оформление и сценарий,
но не заявляет равенства значений телеметрии в разные моменты времени.

## Состояния данных и границы проверки

- Наблюдаемые UNKNOWN, INCOMPLETE и TELEMETRY MISSING сохранены. Они отражают
  недостаточную или отсутствующую телеметрию и не заменены зелёным OK.
- Archive UNKNOWN и неполная сохранённая оценка Control Plane не исправляются
  оформлением; соответствующие вопросы остаются в отдельном backlog.
- DQ stat и coverage визуально проверены на реальных доступных данных.
  Дополнительное историческое окно 2026-09-16 13:30–14:30 UTC содержит измеренные
  точки 100%: цвет линии зелёный, пропуски остаются разрывами. Цвет линии следует
  значению, цвет легенды — минимуму наблюдений, что прямо указано в подписи.
  Все промежуточные цветовые пороги на реальных данных недоступны; их соответствие
  проверено тестами, без подмены телеметрии.
- Copy to Clipboard показал штатное подтверждение Copied и полный UUID.
  Виртуальный буфер браузерного инструмента не получил системное содержимое,
  поэтому независимое чтение скопированных байтов этим инструментом не заявляется.
- Экспорт браузера может исключать полосу прокрутки и часть рамки. Реальные
  размеры каждого изображения и запрошенный viewport указаны отдельно в реестре.
- Искусственные QUERY ERROR во всех источниках не создавались. Сохранение
  специальных состояний и реальных нулей проверено применимыми контрактами;
  временная недоступность Docker/резервный профиль не засчитаны как приёмка UI.

## Общие принципы и порядок исправлений

Сначала исправлена семантика P1 счётчика. Затем выбор запуска, действия и
предупреждения о полноте. После этого — таблицы, легенды и подписи, затем
компоновка навигации и подробностей. Полные значения доступны через штатный
инспектор, а короткая сводка предшествует подробным доказательствам.

Проверены: **0. Run Explorer, 1. Trust, 2. Overview, 3. Pipeline Diagnostics,
4. Provider Health, 5. Data Quality, 6. Incident Workspace**.

Развёрнутые модели всех семи дашбордов совпали с каноническими `panels`,
`templating`, `links`, `title`, `uid` версии `ef8e2c08c37`; дополнительное исправление
цвета истории DQ внесено в `4b90bd4eda0` и проверено повторно.
API собран из `92ce8db470e`; последующий коммит меняет dashboard presentation,
тесты и generated quality artifacts, без изменения API source.
Подробные SHA-256, журналы проверок и отобранные after-снимки входят в пакет
приёмки. Локальная визуальная приёмка не означает прохождение внешнего CI или
закрытие общей программы наблюдаемости #10431/#10440.
