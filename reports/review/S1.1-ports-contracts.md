### NAME (Naming)

| # | Rule | Severity | File | Description |
|---|------|----------|------|-------------|
| 1 | NAME-001 | MEDIUM | `ports/adr.py` | `AdrDocument`, `AdrValidationIssue`, `AdrValidationReport` -- dataclasses without standard suffix |
| 2 | NAME-001 | MEDIUM | `ports/memory.py` | `MemoryStats` -- dataclass, acceptable as domain value object (EXC-015) |
| 3 | NAME-001 | MEDIUM | `ports/metadata_coordinator.py` | `BronzeMetadataInput`, `SilverMetadataInput`, `SilverRef`, `GoldMetadataInput` -- DTO-like dataclasses |
| 4 | NAME-001 | MEDIUM | `ports/noop.py` | `NoOpTracing`, `NoOpMetrics`, `NoOpAudit`, `NoOpPiiHasher`, `NoOpMemoryMonitor`, `NoOpMetadataWriter` -- Null Object implementations, intentionally without `*Adapter` suffix |

**Assessment:** These are data transfer classes and Null Object implementations co-located with ports for convenience. The naming is descriptive and follows the Null Object convention (`NoOp*`). `MemoryStats` is a value object (EXC-015). `*MetadataInput` and `SilverRef` are DTOs used for port method parameters. Not flagging these as real violations since they are value objects/DTOs, not services or adapters.
