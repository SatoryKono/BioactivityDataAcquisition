## File-by-File Notes

### Base Adapters (6 files)
- **`base.py`** (BaseHTTPAdapter): Abstract base requiring `UnifiedHTTPClient`. Implements `aclose()`, `__aenter__`/`__aexit__`, `provider_name`. Template for all HTTP adapters.
- **`base_metrics.py`**: Mixin for adapter-level metrics (request count, duration, batch size, deduplication).
- **`sync_base.py`** (BaseSyncAdapter): Synchronous adapter base for non-HTTP adapters. Implements `aclose()`.
- **`error_handling.py`**: Error classification and handling utilities. Maps HTTP status codes to retry/abort decisions.
- **`filterable_mixin.py`**: Mixin for adapters supporting ID-based filtering (`filter_ids`, `filter_field`).
- **`health_check_mixin.py`**: Two implementations -- `HealthCheckMixin` (simple) and `HealthCheckHTTPMixin` (HTTP endpoint-based). Both return `HealthStatus`.

- **`http/circuit_breaker.py`** (CircuitBreaker): State machine (CLOSED/OPEN/HALF_OPEN). Uses `time.monotonic()` (deterministic). Emits metrics via MetricsPort. Thread-safe with `asyncio.Lock`.
- **`http/rate_limiter.py`** (TokenBucket): Token bucket algorithm. Uses `time.monotonic()`. Factory functions for provider-specific configurations.
- **`http/health.py`**: `assess_health_from_circuit_breaker()` -- maps CB state to HealthStatus.
- **`http/health_monitor.py`** (ProviderHealthMonitor): Centralized health state machine per provider. Uses `time.monotonic()`. Configurable thresholds.
- **`http/pagination.py`** (PaginatedFetcherMixin): Async iterator for paginated API responses.
- **`http/__init__.py`**: Clean re-exports with `__all__`.

### Common Utilities (4 files)

- **`common/title_matching.py`**: `normalize_title()` and `titles_match()` with exact/substring/fuzzy (Jaccard) methods. Pure functions.
- **`common/__init__.py`**: Clean re-exports.

## Findings

### LOW: `datetime.now(UTC)` in api_request_collector.py

**File:** `src/bioetl/infrastructure/adapters/common/api_request_collector.py:116`
**Rule:** Determinism (ADR-014)
**Severity:** LOW
**Details:** The `record_request()` method uses `datetime.now(UTC)` as a default parameter value for `timestamp`. However, this is used only when no explicit timestamp is provided, and the primary caller (Bronze write path) passes explicit timestamps. The default is a convenience fallback for development/testing.

```python
timestamp=timestamp or datetime.now(UTC),
```

**Recommendation:** Consider requiring `timestamp` as mandatory to enforce determinism in all paths, or document the fallback as intentional.

### INFO: Duplicate `_BUCKET_FACTORIES` in rate_limiter.py

**File:** `src/bioetl/infrastructure/adapters/http/rate_limiter.py`
**Details:** Lines 190-193 appear to have a duplicate assignment of `_BUCKET_FACTORIES`. This is a minor code smell but does not affect runtime behavior (the second assignment simply overwrites the first).

**Recommendation:** Remove the duplicate assignment.
