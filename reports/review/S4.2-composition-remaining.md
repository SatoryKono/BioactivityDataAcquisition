## Findings

### Finding F-S4.2-001: structlog Import in Composition Layer (MEDIUM)

**Rule:** AP-002 (structlog usage restricted to infrastructure/observability only)
**File:** `/src/bioetl/composition/bootstrap_logger.py` (line 27)

```python
import structlog
```

The `bootstrap_logger.py` module directly imports `structlog` in the composition layer. Per AP-002, `structlog` should only be imported in `infrastructure/observability/`.

**Mitigating factors:**
- This module is specifically for bootstrap-phase logging before the pipeline's LoggerPort is available
- The BootstrapLogger wrapper provides a LoggerPort-like interface
- Module docstring explicitly documents the requirement: "REQ-OBS-004: Structured JSON format"

**Recommendation:** Consider moving the structlog bootstrap logger to `infrastructure/observability/bootstrap_logger.py` and importing the wrapper class from there. This would keep infrastructure-specific imports properly isolated. Alternatively, document this as an accepted exception in the file.

**Severity:** MEDIUM (-0.5)

---

### Finding F-S4.2-002: Module-level Mutable State in ProviderRegistry (MEDIUM)

**Rule:** DI-004 (import-time side effects)
**File:** `/src/bioetl/composition/providers/provider_registry.py` (line 121)

```python
class ProviderRegistry:
    _providers: ClassVar[dict[str, ProviderConfig]] = {}
```

`ProviderRegistry` uses a class-level mutable `ClassVar` dictionary. While this is a deliberate design choice (module-level registry pattern), it constitutes mutable global state that could cause issues in parallel testing.

**Mitigating factors:**
- The registry has a `clear()` method for test isolation
- Registration is idempotent (re-registration overwrites)
- This is a common pattern for plugin registries
- The PipelineRegistry (registry.py) uses an instance-based approach which is better for test isolation

**Recommendation:** Consider migrating to instance-based pattern (like PipelineRegistry) for better test isolation and thread safety. Not a violation per EXC-015 (Config Classes with Defaults), but noted as a design consideration.

**Severity:** MEDIUM (-0.5)
