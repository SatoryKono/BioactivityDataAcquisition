### NAME (Naming)

| # | Rule | Severity | File | Description |
|---|------|----------|------|-------------|
| 1 | NAME-001 | MEDIUM | Multiple entity files | Several entity/DTO classes lack standard suffix. Examples: `Bioactivity`, `Molecule`, `Target`, `Assay`, `CellLine`, `Tissue` |

**Assessment:** These are core domain entities. In DDD, entities typically use their business name without a suffix like `Entity` or `Record`. The project convention is mixed -- some use `*Record` (Pydantic DTOs: `ActivityRecord`, `AssayRecord`, `MoleculeRecord`) while domain entities use bare names (`Bioactivity`, `Molecule`). This is actually a good separation: DTOs have `*Record` suffix, domain entities use bare business names. **Not a real issue** -- the distinction between Record (DTO) and bare name (entity) is a purposeful convention.
