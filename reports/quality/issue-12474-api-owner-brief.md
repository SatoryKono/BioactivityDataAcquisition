Сохранённый [QM‑01 census](https://github.com/SatoryKono/BioactivityDataAcquisition/blob/35e4c0a9a3a649d43b211c0efc5696c87dd13aed/reports/quality/quality-move-qm01/metadata.json) не нашёл runtime-src consumers вне пакета на своей исходной ревизии. Это аргументы для рассмотрения internal-only, **не доказательство отсутствия внешних пользователей**. Более того, в [историческом pyproject](https://github.com/SatoryKono/BioactivityDataAcquisition/blob/daaf6fef51ff3f502c2a46121d1dffe2f6555a7c/pyproject.toml) поиск пакетов охватывал `src` без исключения quality. Исторические опубликованные wheel здесь не проверены; source/editable installs, прямые imports и сторонние automation остаются пробелом. [QM‑01 compatibility decision](https://github.com/SatoryKono/BioactivityDataAcquisition/blob/35e4c0a9a3a649d43b211c0efc5696c87dd13aed/reports/quality/quality-move-qm01/reference_decisions.json) сохраняет исторический BLOCKED с отсутствующим owner. `__all__` не определяет согласованную support policy.

## Если владелец выбирает breaking change

Затрагиваются старые 30 import paths и конфигурационные/dynamic references. В runtime wheel нового engineering namespace тоже нет, поэтому wheel-only клиенту недостаточно заменить import. Совместимого shim из core в scripts нет и добавлять его в обход границы нельзя. Project version в наблюдавшемся main и candidate остаётся `6.1.0`; согласованное version/changelog решение этим не подтверждается.

План для согласования: определить поддерживаемых downstream consumers; объявить removal и точный replacement contract; для source-only automation использовать engineering checkout/распакованный sdist и штатные engineering entrypoints с его зависимостями. Для wheel-only потребности владелец должен отдельно определить поддерживаемый runtime interface/дистрибуцию, не обещая отсутствующий drop-in API. Согласовать release version, changelog, migration guide и уведомление потребителей; повторить затронутые import/root/behavior/packaging checks. Проверенный полный обратный changeset QM‑09 сохраняется отдельным требованием, без отката pipeline data/форматов/пользовательской памяти.
